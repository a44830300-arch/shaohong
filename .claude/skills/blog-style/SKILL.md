# 블로그 게시글 스타일 (smile0300)

2026-11-20에 최근 글 18개(2024-08 ~ 2026-11)를 읽고 정리함. 블로그 이름은 맛집 후기 위주(카테고리: 제주맛집·맛집리스트·제주빵집•떡집·타지맛집·[블챌] 포토덤프).
블로그 글을 대신 쓸 때는 **아래 뼈대와 말투를 그대로 따른다.** 사실(주소·영업시간·가격·맛)은 강정준비준이 준 정보만 쓰고, 모르는 칸은 비워 두고 물어본다.

## 말투는 두 가지 — 기본은 ① 최근 말투

두 말투 모두 강정준비준이 직접 쓴 것이다(2026-11-20 확인). 시기에 따라 말투가 바뀌었을 뿐이다.

- **① 최근 말투 (2026-10월~, 지금 쓰는 말투, 기본):** 일기처럼 솔직하고 장난스러움.
  - "~했습니다 / ~했어요"를 섞는다. 혼잣말·속마음을 넣는다: "아 침고여", "레전드", "무적권", "이야... 저 스키야키 좋아하는 거 같아요".
  - 이모티콘 대신 글자 표정: `:>` `:D` `ㅎㅎㅎ` `ㅠㅠ` `ㅋ.ㅋ` `^.^` `ㅎㅂㅎ` `;>`
  - 누구랑 갔는지 꼭 말한다: "친구 놈이랑", "엄마랑 데이트", "같이 온 동료분이", "여자친구랑 오려고요".
  - 강조는 반복과 느낌표: "정말정말정말 괜찮았어요", "꼭!! 바로 드셔야 합니다. 꼭!!", "너~~무 맛있어요!", "전~혀 안 났어요".
  - 자기 취향을 밝힌다: "제가 또 와인을 좋아하기 때문에", "원래는 무조건 아아만 먹는데", "후추간 좋아하거든요".
  - 다음에 또 올 계획으로 맺는다: "다음에는 고등어회를 먹어보려고요!", "다음에 방문하게 된다면 꼭 후기 들고 올게요~!!"
- **② 예전 말투 (2024년 글, 2026-09 문문선 글):** 정돈된 리뷰체. "~어요/~해요" 위주, 맛 묘사가 꼼꼼함(식감·향·간), "호불호 없이", "~굳!", "장난 없어요", "but"/"But" 섞어 쓰기. 인사 "안녕하세요 소장용입니다~".
- 강정준비준이 말투를 따로 정하지 않으면 ①로 쓴다.

## 제목 짓기

- **검색어(지역+맛집 종류)를 앞에, 가게 이름을 뒤에** 넣는다.
  - 예: "제주 고기국수 현지인 맛집 만세국수(면리필 가능)", "성산일출봉 맛집 갈치와 성산점｜아이랑 먹기 편한 순살 갈치조림, 제주 동쪽 맛집 후기"
- 최근에는 **말 거는 제목**이 늘었다: "제주공항근처맛집 찾고 있어요? 기념일엔 ○○ 가 보세요", "제주도 용담 가요? 저녁은 ○○에서 하시죠", "제주도 동쪽(표선) 여행 중이시면 꼭 들리세요. '○○'"
- 자주 쓰는 꼬리말: `내돈내산`, `솔직후기`, `후기`, `메뉴 추천`, `BEST3`, `○곳 추천`, 괄호 속 장점(면리필 가능·다이빙, 스노쿨링 명소).
- 비교 제목도 쓴다: "하이디라오보다 좋았던 제주훠궈 ○○"

## 글 뼈대 (가게 하나 후기)

1. **(선택) 대표 사진 1장**
2. **인용구 = 가게 이름**
3. **정보 박스** (한 줄씩, 굵게 또는 15~16 크기) — 이 순서:
   ```
   상호 : 
   주소 : 
   영업시간 : 00:00 ~ 00:00
   - 브레이크타임 : 
   - 라스트오더 : 
   - 정기휴무일 : 
   방문시간 : 평일/주말 ○시
   웨이팅 : 없음 / x / 1팀
   주차장 : 
   좌석 : 
   추천메뉴 : 
   개인생각 : (한 줄 총평, 이게 글의 핵심 문장)
   *자세한 내용은 아래 본문을 참고해 주세요:)👇
   ```
   - 칸이 없으면 줄을 빼거나 `x`로 적는다. 장소마다 맞는 칸을 더한다(떡집: "떡 나오는시간", 바다: "샤워장·수심/파도", "반려동물 동반 가능").
4. **네이버 지도(장소 카드)** → **구분선**
5. **인용구 = 큰 제목** 2줄: "검색어 / ○○ 후기" (예: "제주 용담 횟집 / 용담엔회포차 후기")
6. **인사·도입 1~3줄**: "오늘은 ○○에 위치한 ○○을 소개해드리려 합니다!" / "혹시 ○○ 찾고 계시나요??" / "오늘은 이미 다들 아시는 곳입니다!"
7. **인용구 소제목으로 나눈 본문.** 거의 항상 이 순서:
   - `위치, 주차장(, 좌석, 영업시간)` → 찾아가는 법(버스·도보·차 몇 분), 주차 팁
   - `메뉴` → 메뉴판 사진 + 무엇을 시켰는지
   - `메뉴 이름` (가격까지 적기도: "꾸덕로제리조또 18,000원") → 메뉴마다 소제목 하나
   - `실내 및 매력 포인트` / `인테리어` / `특이사항` / `#부록` → QR주문, 충전기, 셀프바, 유아의자, 사장님 메모 같은 작은 장점
   - `마무리`
8. **사진 1장(또는 사진 묶음·슬라이드) → 그 아래 1~4줄 설명**을 계속 반복한다. 글이 사진보다 길어지지 않는다.
9. **마무리**: 한 줄 총평 + "○○ 들리실 일 있으시면 꼭! 가보시는 걸 추천드립니다!" + (최근) 다음 방문 계획.
10. **스티커**를 소제목 사이·끝에 하나씩 넣는다.
11. **해시태그 3개**를 맨 끝 본문에 적는다: `#지역+종류맛집 #가게이름 #특징키워드` (예: `#제주훠궈 #탕궁샤브 #제주하이디라오`). 최근 글(2026-10월~)은 태그를 안 넣는 경우가 많다 — 넣을지 물어보거나 넣어 둔다.

## 체험단(협찬) 글 (2026-11-20 요청)

- 본문에 "체험단", "제공받아 작성" 같은 말은 **쓰지 않는다.** 네이버 에디터의 **#협찬** 표시만 글 맨 위에 넣는다(초안에 `[#협찬 표시]` 자리만 적어 둔다).
- 체험단 조건(예: 키워드·사진 15장 이상·1,000자 이상·지도·동영상 또는 GIF·공정위 표기)을 받으면 초안 맨 위에 조건 체크 줄을 달고 하나씩 맞췄는지 확인한다. 글자 수는 사진 자리 표시를 빼고 공백 제외로 센다.
- **초안 파일은 사진 폴더 안에도 같이 넣는다** (2026-11-20 요청). 고른 사진을 모은 `올릴사진` 폴더(예: `OneDrive/블로그/블로그/가게이름/올릴사진/`)에 `가게이름_붙여넣기.txt`를 복사해 둔다. 저장소 `블로그/`에도 그대로 둔다.
- 업체 요청사항(키워드·해시태그·꼭 넣을 문장)이 오면 키워드는 제목과 본문 문장 속에 자연스럽게 넣고, 해시태그는 요청한 것을 전부 맨 끝에 적는다. 요청한 주변 관광지는 "동쪽여행 코스"처럼 코스 칸을 따로 만들어 연결한다.

## 여러 곳을 묶은 글 (BEST3·○곳 추천·하루 두 곳)

- 가게마다 **[인용구 이름 → 정보 박스 → 지도 → 구분선 → 메뉴별 사진+글]**을 통째로 반복한다. 가게 사이는 스티커나 구분선.
- "첫번째/두번째/마지막은~"으로 이어 간다.
- 장소 소개(바다 수영 스팟 등)는 문장을 **짧게 줄바꿈**(한 줄 10~15자)해서 시처럼 쓴다. 끝은 "끝-!"

## 본문 쓰는 요령

- **검색 키워드를 본문에 여러 번 넣는다.** 가게 이름 앞에 지역 수식어를 바꿔 가며 붙인다: "성산일출봉 맛집 갈치와 성산점", "제주 동쪽 맛집 갈치와 성산점", "성산일출봉 갈치맛집 갈치와 성산점". (네이버 검색 노출용)
- 맛 표현: 식감(쫀득·고슬고슬·탱글·툭툭 끊기는) + 향 + 간(짭조름·슴슴·자극적이지 않은)을 같이 적는다. "호불호"를 자주 짚는다.
- **아쉬운 점은 쓰지 않는다** (2026-11-20 요청). 예전 글에 있던 "별로더라구요", "아쉬웠어요" 같은 단점 문장은 넣지 않고 좋은 점·팁 위주로 쓴다.
- **현지인 시선**을 강조한다: "현지인인 저의 최애", "현지인픽".
- 누구에게 좋은지 짚는다: "조부모님이나 부모님과 함께 오면 좋겠다", "혼밥하러도", "데이트로도", "회식장소로도", "외국인분들도 먹기 편할 것 같다".
- 가격은 숫자 그대로(25,000원) + 감(인당 1.5만원 정도, 다른 곳보다 저렴한 편).
- 사진 설명 짧은 말: "완전체입니다", "풀샷입니다!", "조금 더 자세히", "조금만 더!", "짜잔~", "레전드".
