# 축제달력 자체 피드백 (올리기 전 확인)

> 2026-11-02 요청. 축제달력은 강정준비준이 직접 만들고, 다 만든 뒤 올리기 전에 이 목록으로 스스로 확인한다(⑤ 자체 피드백). 크리링이 축제달력 사진을 받으면 묻지 않아도 이 목록으로 봐 준다. 공통 규칙(호칭·한국어·중요도 표시 등)은 CLAUDE.md를 따른다.

## 확인 목록

- [ ] **축제마다 그 축제 사진이 들어갔는지 (꼭)**: 달력에 적은 축제 하나하나에 **그 축제의 실제 사진**이 있어야 한다. 다른 축제 사진이나 아무 제주 풍경 사진으로 대신하지 않는다. 사진이 빠진 축제가 있으면 축제 이름을 짚어서 알려 준다.
