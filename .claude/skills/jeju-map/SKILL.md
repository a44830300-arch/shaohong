# 지도·귤지도

> CLAUDE.md에서 옮겨 온 규칙이다(2026-11-01, 크레딧 절약). 내용을 바꾸면 이 파일을 고친다. 공통 규칙(호칭·한국어·중요도 표시 등)은 CLAUDE.md를 따른다.

- **지도에 가게·장소를 찍을 때는 실제 위치가 가장 중요하다** (2026-10-25 요청). 보기 좋게 옮기지 말고 실제 주소 자리에 둔다. 겹치면 핀·이름표 크기를 줄인다(읽기 불편하지 않을 정도까지). 이름표는 박스 없는 하얀 굵은 글씨(핼러윈 지도 스타일)로 쓴다. **이름표 위치는 사용자가 피그마에서 직접 조정하므로 겹쳐도 상관없다** (2026-10-26 요청). 이름표 자리 맞추느라 시간 쓰지 않는다.
- **귤지도 위치 기준 (2026-10-26):** `샤오홍슈/감귤카페/귤지도*.svg`는 실제 해안선(OpenStreetMap)에 맞춘 좌표로 핀을 찍었다. 가게 좌표는 관광공사 자료(ktriptips)·여기유·다이닝코드에서 가져왔다. **귤 핀 모양 (2026-10-30, 앞으로 항상 이 그림자 버전):** 크기 56x74, 흰 외곽선 1, 아래 고리 없음, 핀 끝 바로 아래에 기울지 않은 납작한 타원 그림자(진갈색 30%)를 넣는다. 기본 핀 `pin_tangerine.svg`도 그림자 버전이다. **가게 지도는 지도 한 장에 가게 하나**만 찍는다(예: `샤오홍슈/감귤카페/가게별지도/` 8장). **가게 지도 크기는 310x182, 가게 지도의 귤 핀은 52x73** (2026-10-31 다시 요청).
- **축제달력 지도 위치포인트 (2026-11-01 요청):** 축제달력 지도에는 축제마다 **그 테마에 맞는 아이템 모양 핀**을 하나씩 찍는다. 모양은 귤 핀과 같다(56x74, 흰 외곽선 1, 귀여운 얼굴·볼터치, 핀 아래 납작한 진갈색 30% 그림자). Claude는 달력을 만들지 않고 **위치포인트만** 만든다. 만든 핀은 `샤오홍슈/축제달력/위치포인트/`: 노래방마이크, 결혼_반지, 결혼_웨딩케이크, 커플_하트, 배낭, 야시장_홍등. 얼굴 없는 버전(테마색 물방울 핀 + 하얀 원 안 아이템 아이콘)은 `위치포인트/아이콘핀_얼굴없음/`에 있다(2026-11-01). **마이크 위치포인트는 `pin_마이크_실버보라.svg`를 쓴다 (2026-11-01 선택):** 물방울 핀 버전(얼굴 있음·없음) 둘 다 마음에 안 든다고 해서, **마이크 모양 자체가 핀**(은색 그물 머리 + 금색 띠 + 보라 손잡이가 뾰족하게 좁아져 끝이 위치, 분홍 음표·노란 반짝이)으로 새로 만들었다. 다른 아이템 핀을 새로 만들 때도 이 "아이템 자체가 핀" 방식을 먼저 제안한다. 사용자가 아이템을 모르겠다고 하면 크리링이 중국인 관광객이 바로 알아볼 아이템으로 정한다.
- **단풍지도 (2026-11-03):** `샤오홍슈/단풍지도/`에 2030 여성용 단풍 사진 명소 10곳 지도(오름·산 제외)와 리스트. 위치포인트는 "아이템 자체가 핀" 방식의 **단풍잎 핀**(`pin_단풍잎.svg`)과 **은행잎 핀**(`pin_은행잎.svg`, 은행나무길용). 명소가 제주시 쪽에 몰려 있어 지도 핀은 46x60으로 줄였다.
- **기본지도 랜드마크 (2026-11-03 요청, "심플하게"):** `샤오홍슈/기본지도/제주_기본지도_랜드마크.svg` — 핀 없는 노멀 제주 지도에 랜드마크 3곳만 표시. 흰 원(반지름 18) 안에 단순한 아이콘 + 아래 납작한 그림자: ✈️ 제주공항(파란 비행기)·⛰️ 성산일출봉(초록 분화구 산 + 주황 해)·🌴 중문관광단지(야자수 + 파도). 이름표는 18px 하얀 굵은 중국어(济州机场·城山日出峰·中文旅游区). 다른 지도(단풍지도·귤지도)에는 넣지 않는다. 이 바탕 지도는 해안선이 단순화돼 성산 실제 좌표가 지도 밖으로 나가므로 성산일출봉은 섬 동쪽 끝 안쪽에 둔다.
