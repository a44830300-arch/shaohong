# 제주 날씨달력 만들기

## 크레딧 아끼기 (꼭 지킨다)
- `gen_weather.py`, `icons/`, `sample.png`는 **열어 보지 않는다.** 디자인은 스크립트에 고정돼 있으니 실행만 한다. 사용자가 디자인을 바꿔 달라고 할 때만 연다.
- 웹 검색은 하지 않는다. 아래 주소만 WebFetch로 읽고, 질문은 "날짜별 최저/최고, 오전·오후 날씨, 강수확률만 표로"처럼 필요한 값만 짧게 달라고 한다.
- 미리보기 PNG는 사용자가 원할 때만 만든다. 글자 넘침은 스크립트가 경고로 알려 준다.
- 결과 보고는 아래 "알리기" 항목만 짧게.

## 기간
- 시작일: 사용자가 말한 날. 없으면 다음 월요일(오늘이 월요일이면 오늘). 토요일 자동 실행이면 이틀 뒤 월요일.
- 시작일부터 14일, 월~일 7칸 × 2줄. 1~10일째는 기상청, 11~14일째는 AccuWeather.

## 데이터 (못 가져온 값은 지어내지 말고 "--"로 두고 알린다)
1. **기상청 (1~10일째)**: https://www.weather.go.kr/w/wnuri-fct2021/main/digital-forecast.do?code=5011000000&unit=m%2Fs&hr1=Y (제주시)
   - 강수확률은 오전·오후 중 큰 값.
   - 10일째까지 없으면 중기예보 PDF: https://www.weather.go.kr/w/repositary/xml/fct/rpt_wid_week_YYYYMMDD0600_184.pdf (YYYYMMDD = 오늘, 18시 발표분은 1800). 그래도 없으면 AccuWeather로 채우고 알린다.
   - 아이콘(오전·오후 중 하나라도 해당하면, 위에서부터): 비·소나기·눈·빗방울 → rain / "흐림" → cloudy / "구름많음" → partly / "맑음" → sun
   - kma.go.kr/jeju 페이지는 읽히지 않으니 쓰지 않는다.
2. **AccuWeather (11~14일째)**: https://www.accuweather.com/ko/kr/jeju/224209/10-day-weather-forecast/224209
   - °C = (°F−32)×5/9 반올림.
   - 10일 페이지에 없는 날은 월간 페이지(…/224209/november-weather/224209 처럼 영문 월)에서 최고·최저만, 강수확률 "--".
   - daily-weather-forecast 페이지는 차단돼 있으니 시도하지 않는다.
   - curl·WebFetch는 403으로 막힌다 → **크리링 브라우저(Claude_Browser) navigate + get_page_text로 읽으면 된다** (2026-11-21 확인). 월간 페이지 아이콘은 `a.monthly-daypanel img[alt]`.
   - (2026-11-21 확인) 기상청 동네예보는 6일치까지만 나온다. 그다음은 중기예보 PDF 글자가 깨지니 `https://www.weather.go.kr/w/weather/forecast/mid-term.do`를 curl로 받아 "제주도" 줄(날씨·강수확률)과 "제주" 최저/최고 줄을 읽는다.
   - 아이콘(위에서부터): 비·소나기·뇌우·눈 → rain / "맑음"이고 "흐림" 없음 → sun / 대체로 흐림·약간 흐림·구름 조금·점차 흐려짐·구름이 줄어듦 → partly / 그냥 "흐림" → cloudy
3. **일출·일몰**: https://www.badatime.com/67/sunrise-set — 첫날~마지막날 (예: sunrise "06:47~06:59", sunset "17:48~17:36"). 못 가져오면 NOAA 식(제주시 33.4996N, 126.5312E, KST)으로 계산하고 계산값이라고 알린다.

## data.json 규칙
- 형식은 `data.example.json`과 같다. days는 정확히 14개, 각 `[라벨, 아이콘, 최저°C, 최고°C, 강수확률]`.
- 라벨은 숫자만("26"). 달이 바뀌면 새 달 1일만 "11.01", 그 뒤는 다시 숫자만.
- month = 첫날의 달("10月"). source = "济州地方气象厅·AccuWeather".
- note(포스트잇 한마디): 2주 중 가장 눈에 띄는 변화를 중국어 간체 12자 안팎. 예: "28日起明显降温"(28일부터 기온이 확 떨어져요), "11月初雨天较多"(11월 초에는 비 오는 날이 많아요).

## 표지 글씨 (2026-11-22 요청)
- 표지(첫 장) **큰 글씨는 「济州天气」(제주 날씨)만** 쓴다. 「11月济州天气」처럼 앞에 달(○月)을 붙이지 않는다. 날씨달력 표지 문구를 제안하거나 만들 때 항상 이렇게 한다.
- 그 아래 날짜(예: 11.23-12.06)와 작은 글씨(예: 按温度穿搭·圣诞活动)는 지금처럼 둔다.

## 만들기
1. data.json을 스크래치 폴더(없으면 /tmp)에 쓴다.
2. 실행: `python3 .claude/skills/weather-calendar/gen_weather.py <data.json> 샤오홍슈/날씨달력/날씨달력_MMDD-MMDD` (추가 설치 필요 없음)
3. "경고"가 나오면 data.json을 고쳐 다시 실행한다.
4. SendUserFile로 SVG를 보낸다.

## 알리기 (짧게, 쉬운 한국어)
- 기간, 어느 날까지 기상청이고 어디부터 AccuWeather인지
- 포스트잇 문구: 중국어 + 병음 + 한국어 뜻
- "--"로 둔 날, 기온이 크게 바뀌는 날
- 피그마: SVG를 캔버스에 끌어다 놓고 "배경_하늘사진으로_교체" 레이어를 지운 뒤 하늘 사진을 넣으면 끝.
