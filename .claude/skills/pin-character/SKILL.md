# 핀 캐릭터 (2026-11-01)

## 모양 규칙 (세트로 보이게 꼭 지킨다)

- 색: 핀·팔다리·손·신발 모두 **빨강 #EF3D32**. 소품(깃대·체크무늬 등)만 **진회색 #2B2B2B**. 단, 무엇인지 알아봐야 하는 생물(방어 등)은 진짜 색을 쓰고 진회색 테두리를 두른다(방어: 등 남색 #2E5C8A, 배 은색, 노란 줄·꼬리 #F6C343). 효과선은 빨강 투명도 45%.
- 팔다리: 굵기 6, 끝 둥글게. 팔꿈치·무릎은 꺾인 선 한 번. **손 = 동그라미**, **발 = 둥근 운동화(15×8 둥근 사각형)**.
- **흰 테두리 스티커 모양**: 핀·팔다리·손·발·소품 전체를 흰 테두리로 한 번에 감싼다(흰 테두리 층 → 소품 → 팔다리 → 핀 순서로 쌓아 팔다리가 몸에 붙어 보이게).
- 몸을 동작 방향으로 살짝 기울인다(뛰기 +10°, 환영 −8°).
- 움직임은 연한 빨간 **효과선**(속도선·흔들기선·펄럭선)으로 보여 준다. 효과선은 따로 레이어로 두어 지울 수 있게 한다.
- 결과물은 **피그마용 SVG**. 레이어 이름은 한국어(효과선 / 흰 테두리 / 소품 / 팔다리 / 핀).

## 만드는 법

1. `pin_character.py`의 `POSES`에 새 포즈를 하나 더 넣는다. 좌표는 원래 핀 기준(61×86, 뾰족한 끝 = (30.5, 83)). 기존 포즈의 팔다리 좌표를 고쳐 쓰면 크기·모양이 저절로 맞는다.
   - 팔 시작점: 몸 옆 (10, 44~46) / (51~52, 42~44), 다리 시작점: (22~24, 62~63) / (37~40, 60~63).
   - 소품은 `prop_outline`(흰 테두리용)과 `prop`(본체)를 같이 넣는다. 깃발 예시는 `checker_flag()`.
2. `python3 .claude/skills/pin-character/pin_character.py <포즈> 샤오홍슈/아이콘/올레_○○핀.svg "올레 ○○핀"`
3. `node .claude/skills/pin-character/preview.js <svg> <png>` (`NODE_PATH=$(npm root -g)` 붙여 실행)로 연두 배경·흰 배경 미리보기를 만들어 **직접 보고** 잘림·어색함을 고친 뒤 준다.
   - **여러 명(커플 등)**: `GROUPS`에 (크기, [(포즈, 위치, 좌우뒤집기, 이름)], 효과, 맨 앞 소품)을 넣는다. `build_group()`이 두 사람의 흰 테두리를 먼저 깔아 한 스티커로 붙인다. 왼쪽 사람은 오른쪽 포즈를 뒤집어 쓴다(예: `sing_duet`). 하트는 `heart()`.
4. SVG와 미리보기 PNG를 `샤오홍슈/아이콘/`에 저장하고 사용자에게 보낸다. 새 포즈를 만들면 위 표에 한 줄 더한다.
