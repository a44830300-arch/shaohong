# 게시물 작업 시간과 단계

> CLAUDE.md에서 옮겨 온 규칙이다(2026-11-01, 크레딧 절약). 내용을 바꾸면 이 파일을 고친다. 공통 규칙(호칭·한국어·중요도 표시 등)은 CLAUDE.md를 따른다.

- **게시물 만들기 시간 (2026-10-30 요청):** 샤오홍슈 게시물은 **한 주제당 이틀, 하루 3시간까지만** 쓴다(한 주제에 최대 6시간). 일 순서를 정할 때 게시물 작업은 하루 3시간을 넘겨 배치하지 않고, 이틀 안에 끝나도록 조각을 나눈다. 3시간이 차면 "오늘은 여기까지"라고 알려 준다.
- **콘텐츠별 작업 순서 (2026-10-30 정함):** 게시물 할 일을 Todoist에 넣을 때는 **아래 단계를 하위 할 일로 꼭 같이 넣는다**. 걸리는 시간은 **할 일 이름 끝에 괄호로 꼭 적는다**(예: "감귤체험 ① 레퍼런스 찾기 (1시간)", Todoist·할 일판에서 바로 보이게, 2026-10-30 요청). 하위 할 일이 없는 게시물 할 일을 보면 바로 채워 넣는다. **예외: 강정준비준이 단계와 시간을 직접 말하면**(예: "레퍼런스 1시간, 작업 1시간 30분, 캡션 20분") 기본 4단계를 쓰지 않고 **말한 단계·시간 그대로만** 하위 할 일로 둔다. 말하지 않은 단계(기획안 등)를 남기거나 더하지 않는다(2026-10-30 요청). "오늘 할일" 알림에서도 게시물 할 일은 남은 하위 단계(다음에 할 단계)를 같이 말해 준다(2026-10-30 요청).
  - **축제 소개 같은 일반 게시물** (이틀): 1일차 = ① 기획안 짜기 40분(타겟 페르소나 중 누구를 위한 글인지 먼저 정함) → ② 레퍼런스 찾기 1시간 20분 → ③ 작업하기 1시간 / 2일차 = ③ 작업하기 마무리 2시간 → ④ 캡션 짜기 1시간.
  - **날씨달력** (토요일, 1시간): ① 배경 고르기 → ② 축제 고르기 → ③ 특이사항 넣기 → ④ 캡션 짜기.
  - **축제달력** (토요일, 2시간, **강정준비준이 처음부터 끝까지 직접 만든다**): ① 축제 찾기 → ② 배경 고르기 → ③ 작업하기 → ④ 캡션 짜기 → ⑤ 자체 피드백(올리기 전 확인, `festival-calendar-check` 스킬. 축제마다 그 축제 사진이 들어갔는지 꼭 확인, 2026-11-02 추가).
