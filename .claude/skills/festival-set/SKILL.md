# 축제 소개 2장 세트 (2026-11-08 정함)

축제달력의 축제 내용은 **축제 1개 = 2장 한 세트**로 만든다. 크기는 둘 다 **1080×1350**.
기준 견본: 피그마 `샤오홍슈` 파일 `<작업중>달력들` 페이지의 "Frame 207 (방어축제 수정본)"(node 687:2) + "Frame 208 (방어축제 수정본)"(node 687:15).
(피그마 원본은 바꾸지 않는다 → 견본을 복사해서 만든다.)

## 1장: 포스터 + 지도 + 정보

- **배경은 비워 둔다** (사용자 요청). 맨 아래 "배경 (비워둠)" 칸은 채우지 않고, 그 위 검정 50% 덮개(Rectangle 72)는 그대로 둔다. 배경 사진은 축제마다 달라서 강정준비준이 직접 넣는다.
- **포스터 크기 통일:** 높이 **873px 고정**, 너비는 포스터 원래 비율대로, **가로 가운데**, 위에서 **48px**. 원본 포스터를 자르지 않고 전체가 보이게 한다.
- 포스터 아래 `card-map`:
  - 제주 지도 윤곽 + 노란 점(지름 12) + 장소 이름(ZCOOL KuaiLe 17, 노랑). **점은 눈대중으로 대략 위치에 찍는다** (위도·경도 찾지 않음, 사용자 요청). 장소가 여러 곳이면 점을 여러 개.
  - 글 3줄 (ZCOOL KuaiLe 35, 흰색): ① 한 줄 소개(`○○ · ○○`) ② `时间：2026.○.○(요일) – ○.○(요일)` ③ `地点：…`
  - 글이 카드 너비(약 595px)를 넘으면 잘리니 짧게 줄인다. 한글은 이 글꼴에 없어서 중국어·영문만 쓴다.

## 2장: 축제 사진 모음

- 사진은 **구글, 네이버지도, 인스타**(네이버 이미지·블로그 포함)에서 그 축제의 **실제 사진**을 가져온다. AI로 만든 그림·홍보 카드·글자가 크게 들어간 사진은 쓰지 않는다.
- **사진 수·배치는 정해진 것 없음.** 1080×1350을 사진으로 꽉 채우고, 사진 사이 틈은 12px. 사진 모양(가로/세로)에 맞춰 배치를 고른다. 자주 쓰는 배치:
  - 위 가로 1장(1080×500) + 가운데 2장(534×400) + 아래 가로 1장(1080×426) ← 방어축제
  - 왼쪽 세로 1장(534×1350) + 오른쪽 3장(534×442)
  - 위 가로 1장(1080×500) + 아래 세로 3장(352×838) 또는 2장(534×838)
- 흰 테두리·블로그 워터마크는 잘라 내고 넣는다. 사람 얼굴이 크게 나온 아이 사진은 피한다.
- 사진 칸 이름은 `사진1 ○○`처럼 무엇인지 적는다.

## 이름·위치

- 프레임 이름: `축제세트 {번호}-1 {축제이름}`, `축제세트 {번호}-2 {축제이름}`. 1장 오른쪽에 2장을 나란히(가로 간격 1120), 세트끼리는 세로 1550 간격.
- 다 만들면 저작권 이야기는 한 줄로만 알린다(블로그·인스타 사진은 올리기 전에 허락을 받는 게 안전하다). 올릴지는 강정준비준이 정한다.
