## 🎯 이 페이지의 역할

- **할 일판 1은 오로지 샤오홍슈 작업목록만 보여 준다** (2026-11-24). 스케줄(시간표·수업·약속·공무원·전공·마케팅·블로그 체험단)은 할일판2(https://claude.ai/artifact/TwYMBC8WgMe7NwSvZL1H8K)에서 본다. 할 일판 1에 다시 넣지 않는다.
- **나들로그만 다룬다** (2026-11-25 손그림 수정안). 제주라이브 게시물(이름이 "🆘 제주라이브:"로 시작하거나 라벨 `제주라이브`, 「📋 제주라이브 게시물 후보」 밑)은 보여 주지 않고, 계정 옮기기 버튼·제주라이브 칸도 없다.
- 원본 코드: 저장소 `할일판/작업목록.html` (2026-11-28부터 스케줄 탭과 한 앱으로 합침). 고친 뒤 `python 할일판/합치기.py`를 돌려 `할일판/index.html`을 만들고, 그 파일로 같은 주소에 다시 올린다(capabilities: db·sample + Todoist `find-tasks`·`update-tasks`·`complete-tasks`·`find-completed-tasks`·`add-tasks`·`find-tasks-by-date` + Google Calendar `list_events` — 스케줄 탭 몫까지 함께, 빠뜨리면 스케줄 탭이 안 불러와짐).

## 화면 순서 (2026-11-25 손그림 수정안, 위 → 아래)

> 제목 옆·줄 아래 설명하는 작은 회색 글씨는 넣지 않는다 (2026-11-24 요청).

1. **머리줄**: 날짜 · "샤오홍슈 작업목록" · **작업 타이머**(10분·40분·1시간·1시간 20분·2시간, 끝나면 소리·진동) · 새로고침.
2. **🧭 작업 순서** (전 이름 "행동강령"): 기획안 짜기 → 레퍼런스 찾기 → 작업하기 → 마무리 → 캡션 짜기. 안내일 뿐, 체크리스트로 붙이지 않는다. 페이지 안 `STEPS`.
3. **위쪽 두 칸** (휴대폰은 한 줄씩):
   - 왼쪽 **🛠️ 작업중**: 게시물을 체크하면 여기로 온다(Todoist 라벨 `진행중`). 여기서 **체크 = Todoist 완료 → ✅ 끝난 작업물로**, **✕ = 게시물 목록으로 되돌림**(라벨만 뗌). 아래 입력칸에 적으면 Todoist 아이디어 칸에 `진행중` 라벨을 붙여 바로 넣는다(2026-11-25). 카테고리가 있으면 이름 옆에 초록 꼬리표로 보인다.
   - 오른쪽 위 **🗓️ 월별 / 분기별**: 빈 칸에서 시작, 강정준비준이 직접 추가·체크·✕ 지우기. 크리링이 알아서 채우지 않는다.
   - 오른쪽 아래 **📅 이번 주**: □날씨달력 □축제달력 고정 체크박스(월요일마다 빈 칸, 페이지 안 `FIXED`) + **직접 추가한 줄**(2026-11-25, ✕로 지움). 직접 추가한 것 중 못 끝낸 건 다음 주로 넘어가고, 체크한 건 다음 주에 사라진다. 게시물을 옮겨 오는 기능·월요일 라벨 초기화는 없앴다.
4. **🗂️ 게시물**: Todoist "💼 일 > 샤오홍슈 아이디어" 칸 게시물을 **두 줄(2열)**로(휴대폰 좁은 화면은 한 줄).
   - **카테고리 (2026-11-25 요청, "내가 직접 카테고리를 만들고 분류")**: 「🏷️ 카테고리 만들기·고치기」를 누르면 새 카테고리 추가·이름 고치기·↑ 순서 올리기·✕ 지우기(안의 게시물은 '분류 안 함'으로). 게시물마다 오른쪽 고르기 칸으로 카테고리를 정하면 **카테고리별 칸**으로 묶여 보인다(맨 위 '분류 안 함' 칸은 남은 게 있을 때만). 카테고리가 없으면 예전처럼 한 칸. 분류는 페이지 저장소에만 두고 Todoist는 바꾸지 않는다. 크리링이 알아서 카테고리를 만들거나 나누지 않는다.
   - **직접 추가 (2026-11-25)**: 칸마다 맨 아래 입력칸 → Todoist 아이디어 칸에 "🗿 나들로그: 이름"으로 새 할 일을 넣는다(카테고리 칸에서 넣으면 그 카테고리로 바로 분류). 줄마다 **체크 = 작업중으로**, **✕ = 목록에서만 숨기기**(Todoist에는 그대로, 아래 "숨긴 게시물 n개"를 펼쳐 ↩ 되돌리기). 이름 앞 "🗿 나들로그:" 머리말·끝 "(2시간 30분)"은 떼고 보인다.
   - 「📋 ○○ 게시물 후보」 머리 할 일은 묶음이라 보이지 않고 그 밑 할 일은 보인다. **①②③ 하위 단계는 보여 주지 않는다.** 아이디어 칸 것은 빠짐없이(`pageAll`이 Todoist `nextCursor`로 끝까지 불러옴).
5. **✅ 끝난 작업물**: 접었다 펼 수 있는 칸. Todoist에서 완료한 게시물(최근 8주)을 **완료 날짜 기준 월~일 한 주씩** 묶어 보여 준다(페이지 안 `DONE_WEEKS`).
6. **📖 컨텐츠 가이드**: 분류 카드(먹거리·관광지·행사·여행 팁·여행 코스 추천·제주 소개)와 항목. **✏️ 고치기**를 누르면 분류·항목 이름 고치기, 추가, ✕ 지우기. 처음 내용은 손그림 수정안 그대로 넣었다("제주도 날씨를 대비한"은 손글씨 그대로 — 뒷말은 강정준비준이 채움).
