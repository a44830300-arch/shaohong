## 🎨 일정 분류 색 (2026-11-19 요청, "일정마다 너가 분류해서 색깔 다 넣어줘. 점심 저녁+운동만 검은색")

- ⏰ 일주일 시간표의 **모든 칸**(캘린더 일정·Todoist 할 일·수업·평일 고정표·종일)을 크리링이 분류해 색을 칠한다. 오늘 목록·작은 칩에는 같은 색 점을 단다.
- 색: 🟢 샤오홍슈 · 🟡 블로그 · 🔵 학교·전공 · 🟣 공무원 · 🩷 마케팅 · ⚪ 생활(기상·청소·계획·쓰레기) · 🩵 약속·그 밖 · **⚫ 점심·저녁·운동만 검은색**.
- 중요도는 색 대신 **테두리**로: 빨간 테두리 = 꼭(p1·토마토), 노란 테두리 = 중요(p2).
- 분류 순서: 구역(블로그·샤오홍슈·아이디어·공무원·전기) → 캘린더 색(바나나 = 블로그, 바질 = 샤오홍슈) → 이름 낱말. 낱말 목록은 페이지 안 `CAT_RULES`에 있다(점심·저녁·식사·운동·러닝·헬스가 맨 먼저라 검은색이 이긴다). 새 종류의 일정이 늘면 `CAT_RULES`에 낱말을 더한다.
- 색 뜻 표시는 시간표 아래에 있고, 휴대폰 세로에서는 숨긴다.
- 독립 앱(`todo-app/`)에는 아직 안 들어갔다(그 앱은 평일 고정표도 없는 옛날 모양).

## 📋 게시물 후보 칸 (2026-11-17 요청, "계정별로 리스트업만, 내가 직접 고를께")

- "오늘" 바로 아래(휴대폰은 오늘 다음)에 **계정별 게시물 후보** 칸이 있다. Todoist "💼 일 > 샤오홍슈 아이디어"의 머리 할 일 「📋 나들로그 게시물 후보」·「📋 제주라이브 게시물 후보」(완료 안 되는 머리) 밑 하위 할 일을 보여 준다. 설명 첫 줄(왜 추천하는지)을 같이 보여 준다.
- **체크 = 완료가 아니라 Todoist 라벨 '고름'을 붙였다 뗀다.** 고른 것은 초록 줄.
- **크리링은 후보를 알아서 일정에 넣지 않는다.** 강정준비준이 '고름'을 붙인 것만, "고른 거 넣어줘"라고 하면 빈 날(나들로그·제주라이브 번갈아)에 넣는다. 새 후보를 찾으면 알맞은 계정 묶음 밑에 날짜 없이 더한다(설명 첫 줄에 "왜:" + 근거가 데이터인지 판단인지).
- **한 주에 7개 고르기 (2026-11-18 요청):** 강정준비준이 두 계정 합쳐 **7개**를 고르면 그 7개를 **그 주에** 올린다. 칸 맨 위에 "이번 주에 올릴 게시물 ○/7개" 막대(점 7개)와 고른 것 목록이 있고, 7개가 되면 초록, 넘으면 빨강으로 알려 준다. 후보 이름은 앞 계정 표시와 끝 "(2시간 30분)"을 빼고 짧게, 설명 첫 줄은 "왜:"를 빼고 보여 준다.
- **후보는 강정준비준이 적은 아이디어 위주 (2026-11-18 다시 요청, "너가 임의로 넣은 것 말고 내가 적었던 것 위주로"):** 후보 칸에는 강정준비준이 직접 적은 아이디어(아이디어 칸의 짧은 제목들 — 칠성로·동문시장·공항 완전정리, 계절별 오름·꽃, 제주공방, 형/여행코스 등)와 강정준비준이 직접 정한 글(내돈내산, 동백 VOL.01, 휴애리 동백)만 둔다. 이름은 적은 그대로 두고 바꾸지 않는다. **크리링이 떠올린 주제는 후보 칸에 넣지 않고** "💼 일 > 샤오홍슈 아이디어" 칸(묶음 밖)에 둔다. 강정준비준이 "크리링 추천도 넣어줘"라고 할 때만 후보로 올린다. 강정준비준이 새 아이디어를 말하면 알맞은 계정 후보 밑에 그 말 그대로 더한다.
  - 2026-11-18에 크리링 주제 17개(크리스마스·신화월드·유채·카멜리아힐·한라산·성산일출·겨울방학, 제주라이브 막히는 순간 시리즈 등)를 후보에서 빼서 아이디어 칸으로 돌려놨다.
  - **아이디어 칸 전체도 같이 보여 준다 (2026-11-18 요청, "투두이스트 샤오홍슈 아이디어를 구분해서 다 리스트업"):** 계정 카드 안을 **✍️ 내가 적은 후보**(📋 묶음 밑) / **💡 아이디어 칸**(묶음 밖, 이름 앞 🗿 = 나들로그 · 🆘 = 제주라이브)으로 나누고, 계정 표시가 없는 아이디어는 **"💡 계정 안 정한 아이디어"** 카드에 모은다. 카드는 컴퓨터에서 왼쪽·오른쪽 두 기둥에 **더 짧은 쪽으로** 쌓아 한쪽이 비지 않게 한다(2026-11-18 요청, 휴대폰은 한 줄). 설명에 "크리링 판단"이 있으면 파란 **크리링 추천** 표시를 단다. 아이디어 칸 것도 네모로 '고름'을 붙일 수 있고 7개 세기에 들어간다. 하위 단계(①②③)는 보여 주지 않는다. 그래도 크리링은 아이디어를 📋 묶음 밑으로 옮기지 않는다(위 규칙 그대로).
  - **순서는 크리링 추천 순서 (2026-11-18 요청):** 페이지 안 `PICK_ORDER`(할 일 id + 이유)에 적은 순서대로 각 칸을 정렬하고 번호를 단다. 번호는 전체 순위라 카드마다 건너뛸 수 있다. **1~7은 주황 번호 = 이번 주 추천.** 이유는 할 일 밑에 한 줄로 보인다. 기준(크리링 판단): 제철·마감 가까운 것 → 강정준비준이 직접 고른 것 → 두 계정 번갈아 → 바로 만들 수 있는 것. 목록에 없는 새 후보는 맨 뒤에 번호 없이 나오므로, 후보를 더하거나 주가 바뀌면 `PICK_ORDER`도 다시 짠다. 크리링이 정하는 건 순서뿐이고, 고르는 건 강정준비준이 한다.
  - 계정 나눔은 크리링이 짐작한 것이다: 형/여행코스·형/예약관련·공항 완전정리·네이버 지도 이동 영상 = 제주라이브, 나머지 = 나들로그. 강정준비준이 바꾸라면 바꾼다.
- **2026-11-17 실수 기록:** 후보 14개를 고름 표시 없이 날짜를 붙여 일정으로 옮겨서 후보 칸이 비었다. 다시는 고르지 않은 후보를 일정에 넣지 않는다.
- 일정에 넣으면 📊 막대 일정표 샤오홍슈 탭 "이번 주 게시물" 칸(`GANTT.xhs`)도 고른 7개로 바꾼다.
- 이 칸 때문에 할 일판 Todoist 도구에 `update-tasks`가 더해졌다. 앱(`todo-app/`)은 `/tasks?parent_id=`와 `POST /tasks/{id}`(labels)로 같은 일을 한다.

- **컴퓨터 화면에서도 ⏰ 일주일 시간표가 맨 위다** (2026-11-19 요청): 머리줄(타이머) 바로 아래 → 명령 칸 → 오늘 → 📋 게시물 후보 → 📊 막대 일정표 → 📝 체험단 → 날짜 미정.

- **일주일 시간표와 오늘 목록은 한 화면에 보여야 한다.** 그래서 시간표는 7일이 옆으로 밀지 않고 다 보이게 작게 그리고(화면 높이의 절반쯤, 눈금은 홀수 시간도 빼지 않고 매시간(2026-11-11 요청), 칸을 누르면 시간·이름이 아래 말풍선으로 나옴), 오늘 목록은 남은 높이 안에서 따로 밀어 본다. 두 칸의 설명 글(색 뜻 등)은 휴대폰에서 숨긴다.
- **타이머·스톱워치는 자리는 그대로, 크기만 작게** 했다(시간 고르는 버튼은 타이머와 같은 줄에서 옆으로 밀어 봄).
- 페이지 안에서는 맨 아래 "휴대폰 세로 화면" CSS 묶음과 `fitToday`·`drawTimeline`의 `compact` 부분이다.
