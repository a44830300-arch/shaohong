- **스케줄(시간표·수업·약속·공무원·전공·마케팅·블로그 체험단)은 할일판2(https://claude.ai/artifact/TwYMBC8WgMe7NwSvZL1H8K)에서 본다.** 할 일판 1에 다시 넣지 않는다.
- 2026-11-24에 뺀 것: ⏰ 일주일 시간표(구글 캘린더 모양·평일 고정표·`FIXED`·`SCHOOL`·분류 색), 학교·공무원·마케팅이 섞인 "오늘" 목록, 📝 블로그 체험단 현황표, 📌 날짜 미정(블로그), ⌨️ 명령 칸, 📊 막대 일정표의 마킴 탭, 구글 캘린더 불러오기.

## 화면 순서 (위 → 아래)

1. **머리줄**: 날짜 · "샤오홍슈 작업목록" · 오늘 총 작업 시간 · 작업 타이머(10분·40분·1시간·1시간 20분·2시간) · 과목별 스톱워치 4칸(샤오홍슈·전공·마케팅·블로그, 2026-11-05 요청 그대로 둠) · 새로고침.
2. **한눈에 숫자 4칸** (누르면 그 칸으로 내려감): 🔥 지금 할 일(밀린 일이 있으면 빨강) · 📅 이번 주 · 🛠️ 진행 중 게시물(다음 단계) · 📋 이번 주 고른 후보 ○/7. 휴대폰은 2×2.
3. **🔥 지금 할 일**: 오늘까지(밀린 일 포함) 날짜가 잡힌 샤오홍슈 일. 추천 순서 번호(꼭 🔴 → 밀린 일 → 중요 🟠 → 나머지, 같으면 시간순), 다음 1~2개는 주황 번호. 밀린 일은 "○/○ (요일)부터 밀림" 빨간 글씨, 반복 일은 "🔁 매주 토"처럼, 하위 단계면 "게시물: ○○"를 적는다.
4. **📅 이번 주**: 내일부터 7일, 날짜별 소제목 아래 시간순.
5. **🛠️ 진행 중인 게시물**: 하위 할 일(①②③ 단계)이 있는 부모 할 일마다 카드. 남은 단계 수 · 남은 시간(이름 끝 "(1시간 20분)"을 더함) · 설명 첫 줄 · 단계 목록(이름순), 첫 번째 안 끝난 단계는 주황 줄 + "다음" 표시.
6. **📌 날짜 없는 일**: 날짜도 하위 단계도 없는 샤오홍슈 할 일.
7. **📋 게시물 후보** (아래 규칙 그대로).
8. **📊 샤오홍슈 막대 일정표**: 축제 기간 · 이번 주 게시물 · 고정 일정(날씨달력 일 10시, 축제달력 일 20시, 토 만들기) · 목표. 데이터는 페이지 안 `GANTT_XHS`.

- 동그라미를 누르면 Todoist 완료(되돌리기 가능). 반복 일은 다음 날짜로 넘어간다.
- **불러오는 할 일**: Todoist "💼 일 > 샤오홍슈" 구역 전부(하위 단계 포함) + 다른 칸이라도 8일 안에 날짜가 잡혀 있고 이름에 샤오홍슈 낱말(`XHS_WORDS`: 날씨달력·축제달력·날씨지도·옷차림·게시물·나들로그·제주라이브·레퍼런스·썸네일·캡션·르방 등)이 들어간 할 일. "샤오홍슈 아이디어" 칸은 게시물 후보 칸에서만 보여 준다.
- 구글 캘린더는 읽지 않는다(샤오홍슈 일정은 Todoist에 있음).

## 📋 게시물 후보 칸 (2026-11-17 요청, "계정별로 리스트업만, 내가 직접 고를께")

- Todoist "💼 일 > 샤오홍슈 아이디어"의 머리 할 일 「📋 나들로그 게시물 후보」·「📋 제주라이브 게시물 후보」(완료 안 되는 머리) 밑 하위 할 일을 계정별로 보여 준다. 설명 첫 줄(왜 추천하는지)을 같이 보여 준다.
- **체크 = 완료가 아니라 Todoist 라벨 '고름'을 붙였다 뗀다.** 고른 것은 초록 줄.
- **크리링은 후보를 알아서 일정에 넣지 않는다.** 강정준비준이 '고름'을 붙인 것만, "고른 거 넣어줘"라고 하면 빈 날(나들로그·제주라이브 번갈아)에 넣는다. 새 후보를 찾으면 알맞은 계정 묶음 밑에 날짜 없이 더한다(설명 첫 줄에 "왜:" + 근거가 데이터인지 판단인지).
- **한 주에 7개 고르기 (2026-11-18 요청):** 두 계정 합쳐 **7개**를 고르면 그 7개를 **그 주에** 올린다. 칸 맨 위에 "이번 주에 올릴 게시물 ○/7개" 막대(점 7개)와 고른 것 목록, 7개면 초록·넘으면 빨강. 후보 이름은 앞 계정 표시와 끝 "(2시간 30분)"을 빼고 짧게, 설명 첫 줄은 "왜:"를 빼고 보여 준다.
- **후보는 강정준비준이 적은 아이디어 위주 (2026-11-18 다시 요청):** 후보 칸에는 강정준비준이 직접 적은 아이디어와 직접 정한 글만 둔다. 이름은 적은 그대로. **크리링이 떠올린 주제는 후보 칸에 넣지 않고** "💼 일 > 샤오홍슈 아이디어" 칸(묶음 밖)에 둔다. "크리링 추천도 넣어줘"라고 할 때만 후보로 올린다. 강정준비준이 새 아이디어를 말하면 알맞은 계정 후보 밑에 그 말 그대로 더한다.
  - **아이디어 칸 전체도 같이 보여 준다 (2026-11-18 요청):** 계정 카드 안을 **✍️ 내가 적은 후보**(📋 묶음 밑) / **💡 아이디어 칸**(묶음 밖, 이름 앞 🗿 = 나들로그 · 🆘 = 제주라이브)으로 나누고, 계정 표시가 없는 아이디어는 **"💡 계정 안 정한 아이디어"** 카드에 모은다. 카드는 컴퓨터에서 두 기둥에 더 짧은 쪽으로 쌓는다(휴대폰은 한 줄). 설명에 "크리링 판단"이 있으면 파란 **크리링 추천** 표시. 아이디어 칸 것도 '고름'을 붙일 수 있고 7개 세기에 들어간다. 하위 단계(①②③)는 보여 주지 않는다. 크리링은 아이디어를 📋 묶음 밑으로 옮기지 않는다.
  - **Todoist 아이디어 칸에 있는 것은 하나도 빠짐없이 게시물 후보에 보여야 한다** (2026-11-20 요청). 페이지는 `findAll`이 Todoist `nextCursor`로 끝까지 불러온다.
  - **순서는 크리링 추천 순서 (2026-11-18 요청):** 페이지 안 `PICK_ORDER`(할 일 id + 이유) 순서대로 정렬·번호. **1~7은 주황 번호 = 이번 주 추천.** 기준(크리링 판단): 제철·마감 가까운 것 → 강정준비준이 직접 고른 것 → 두 계정 번갈아 → 바로 만들 수 있는 것. 목록에 없는 새 후보는 맨 뒤 번호 없이. 후보를 더하거나 주가 바뀌면 `PICK_ORDER`도 다시 짠다. 크리링은 순서만 정하고, 고르는 건 강정준비준이 한다.
  - 계정 나눔은 크리링이 짐작한 것이다: 형/여행코스·형/예약관련·공항 완전정리·네이버 지도 이동 영상 = 제주라이브, 나머지 = 나들로그. 강정준비준이 바꾸라면 바꾼다.
- **2026-11-17 실수 기록:** 후보 14개를 고름 표시 없이 날짜를 붙여 일정으로 옮겨서 후보 칸이 비었다. 다시는 고르지 않은 후보를 일정에 넣지 않는다.
- 일정에 넣으면 📊 막대 일정표 "이번 주 게시물" 칸(`GANTT_XHS`)도 고른 7개로 바꾼다.
