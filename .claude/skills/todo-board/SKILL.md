# 할 일판 (= 할일판 1 · 샤오홍슈 작업목록)

> CLAUDE.md에서 옮겨 온 규칙이다(2026-11-01, 크레딧 절약). 내용을 바꾸면 이 파일을 고친다. 공통 규칙(호칭·한국어·중요도 표시 등)은 CLAUDE.md를 따른다.

## 🎯 이 페이지의 역할 (2026-11-24 요청, 가장 중요)

- **할 일판 1은 오로지 샤오홍슈 작업목록만 보여 준다.** 스케줄(시간표·수업·약속·공무원·전공·마케팅·블로그 체험단)은 할일판2(https://claude.ai/artifact/TwYMBC8WgMe7NwSvZL1H8K)에서 본다. 할 일판 1에 다시 넣지 않는다.
- 원본 코드: 저장소 `할일판/index.html`. 고친 뒤 이 파일로 같은 주소에 다시 올린다.

## 화면 순서 (2026-11-24 두 번째 정리, 위 → 아래)

1. **머리줄**: 날짜 · "샤오홍슈 작업목록" · **작업 타이머**(10분·40분·1시간·1시간 20분·2시간, 끝나면 소리·진동) · 새로고침.
2. **🟢 지금 하고 있는 일**: "지금 할 일"을 이 이름으로 바꾸고 **안의 내용을 모두 뺐다**(지금은 빈 칸). 무엇을 넣을지는 강정준비준이 정하면 채운다 — 크리링이 알아서 채우지 않는다.
3. **📅 이번 주**: **매주 주기적으로 올리는 고정 콘텐츠만** 리스트업한다. 지금은 🌤️ 날씨달력(토 만들기 → 일 10:00 올리기)·🎉 축제달력(토 만들기 → 일 20:00 올리기) 두 개뿐. 이번 주(월~일)의 토·일 날짜를 자동으로 적고, 오늘은 주황·지난 날은 줄 긋기. 고정 콘텐츠가 늘면 페이지 안 `FIXED`에 더한다. Todoist는 읽지 않는다.
4. **🧭 행동강령**: 기획안 짜기 → 레퍼런스 찾기 → 작업하기 → 마무리 → 캡션 짜기. **게시물 하나를 만들 때의 순서를 보여 주는 안내일 뿐, 게시물마다 체크리스트로 붙이지 않는다** (2026-11-24 요청). 페이지 안 `STEPS`.
5. **🗂️ 게시물 (컨셉별)**: 옛 "진행 중인 게시물" 카드 모양으로, Todoist "💼 일 > 샤오홍슈 아이디어" 칸의 게시물을 **컨셉별 카드**로 나눠 보여 준다. 컨셉: 🌸 계절·제철 · 🌦️ 날씨 · 🎉 축제·연휴 · 📍 장소 완전정리 · 🧾 내돈내산·가게 · 🆘 여행 중 막힐 때 · 🎬 영상·특별 기획 · 📝 메모·준비(게시물 아닌 규칙·준비 작업) · 🆕 아직 안 나눈 것. 나눔은 크리링이 정했고(페이지 안 `CONCEPT_OF` = 할 일 id → 컨셉), 새 아이디어는 이름 낱말로 짐작(`GUESS`)하고 안 맞으면 "🆕 아직 안 나눈 것". 강정준비준이 바꾸라면 바꾼다.
   - 줄마다 계정 표시(초록 = 나들로그, 파랑 = 제주라이브)·이름·설명 첫 줄. 체크 버튼·고르기·추천 번호는 없다.
   - 「📋 ○○ 게시물 후보」 머리 할 일은 묶음이라 보이지 않고, 그 밑 할 일은 그 계정으로 본다. **①②③ 하위 단계는 보여 주지 않는다**(행동강령과 별개).
   - 아이디어 칸 것은 하나도 빠짐없이 보여야 한다(`findAll`이 Todoist `nextCursor`로 끝까지 불러옴, 2026-11-20 요청).
