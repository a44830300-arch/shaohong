# 제주 관광 데이터 찾기

> CLAUDE.md에서 옮겨 온 규칙이다(2026-11-01, 크레딧 절약). 내용을 바꾸면 이 파일을 고친다. 공통 규칙(호칭·한국어·중요도 표시 등)은 CLAUDE.md를 따른다.

- 데이터를 찾을 때 **제주관광공사 빅데이터 사이트** https://data.ijto.or.kr/bigdata/index.do 를 써도 된다(2026-10-26 사용자 허락). 제주관광협회 월별통계(visitjeju.or.kr), 공공데이터포털(data.go.kr)도 쓸 수 있다. 클라우드 환경 네트워크 설정에서 이 주소들이 막혀 있으면 사용자에게 허용을 부탁한다.
- 제주관광협회 월별통계는 주소 끝에 `?year=2025&month=12`처럼 붙여 바로 가져올 수 있다(국적별 입도객 확정치). data.ijto.or.kr은 사이트 쪽 인증서 문제로 클라우드에서 열리지 않으니(2026-10-26 확인) 필요하면 사용자에게 화면 캡처를 부탁한다.
