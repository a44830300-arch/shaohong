# 샤오홍슈 심사 걸릴 요소 확인 (2026-11-05 요청)

강정준비준 요청: "앞으로 피드백이랑 캡션 짤 때 샤오홍슈 심사에 걸릴 만한 요소 다 말해줘."

- 캡션을 줄 때, 사진·카드뉴스 피드백을 할 때 **묻지 않아도** 아래 목록으로 캡션 글자 + 사진 속 글자(샤오홍슈는 사진 글자도 읽는다)를 함께 본다.
- 답변에 **"🚨 심사 체크"** 칸을 따로 두고, 걸릴 만한 것을 🔴 위험 / 🟠 주의 / 🟡 낮음으로 나눠 **바꿀 문구(중국어 + 한국어 뜻)**까지 준다. 없으면 "걸릴 만한 요소 없음"이라고 한 줄 쓴다.
- 샤오홍슈 심사 기준은 다 공개되지 않았다. "흔히 걸린다고 알려진 것" 기준이라고 말하고, 확실한 것처럼 말하지 않는다.
- 크리링이 캡션·디자인 문구를 새로 제안할 때도 이 목록에 걸리는 말은 처음부터 쓰지 않는다.

## 확인 목록

1. **외부 연락·다른 앱으로 끌어가기(导流·引流)** — 가장 많이 걸림
   - "微信(위챗)", "VX", 전화번호, 카톡·인스타·다른 앱 이름, 링크, QR코드, 아이디
   - "微信支付(위챗페이)"처럼 결제 뜻이어도 "微信" 글자 자체가 걸릴 수 있다 → "支持手机支付(휴대폰 결제 가능)"처럼 돌려 쓴다.
   - "加我(나 추가해)", "联系我(연락 줘)", "私信领取(DM으로 받아 가)"를 강하게 반복하면 위험. "欢迎留言或私信(댓글·DM 환영)" 정도는 낮음.
2. **광고법 금지 말(绝对化用语)**
   - 最(가장)·第一·唯一·顶级·100%·全部/绝对·必去·必吃·全网最低 등
   - "全部正品(전부 정품)", "没有假货(가품 없음)"처럼 보증하는 말도 피한다.
3. **숨은 광고(软广)로 보이는 것**
   - 가게 한 곳만 길게 칭찬 + 가격·주소·영업시간 + "快去(빨리 가)" → 광고로 보일 수 있다.
   - 홍보비를 받은 글이면 샤오홍슈 공식 협찬 기능(蒲公英)으로 올려야 한다. 돈을 받았는지 모르면 물어본다.
   - 할인 쿠폰·"报我名字打折(내 이름 대면 할인)"은 위험.
4. **저작권·초상권**
   - 남의 포스터·사진·로고(출처 없이), 얼굴이 크게 나온 모르는 사람 사진, 연예인 사진
5. **민감한 내용**
   - 정치·군사·국가 비교·영토, 중국과 한국을 비교해 깎아내리는 말
   - 술·담배·도박·의료 효과 과장, 다이어트 효과 과장
6. **거짓·과장 정보**
   - 확인 안 된 날짜·가격, "免费(무료)"인데 실제로 돈 드는 경우
7. **팔로우·좋아요 유도(诱导关注·诱导互动)** (2026-11-10 추가)
   - 🔴 선물·추첨을 걸고 팔로우 시키기: "关注+点赞+收藏抽奖(팔로우+좋아요+저장하면 추첨)", "关注送攻略(팔로우하면 공략 줌)"
   - 🔴 팔로우 후 DM으로 자료 받기: "关注后私信领取(팔로우 후 DM으로 받아 가)" — 외부 연락 유도와 겹쳐 더 위험
   - 🔴 맞팔 모집: "互关·互粉(맞팔)"
   - 🟠 겁주기·강요: "不关注就找不到了(팔로우 안 하면 못 찾아)", "求关注(팔로우 해 주세요)"를 여러 번 반복
   - 🟡 가볍게 한 번 권하기는 보통 괜찮다: "喜欢的话可以点个关注～(좋으면 팔로우 눌러 주세요)", "济州新鲜资讯持续更新中(제주 새 소식 계속 올려요)"
8. **기타**
   - 같은 해시태그·같은 문장을 지나치게 반복, 내용과 상관없는 인기 해시태그 붙이기
