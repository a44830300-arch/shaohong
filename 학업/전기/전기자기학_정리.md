## 1. 경도(기울기)의 회전은 왜 0인가 — ∇ × (∇φ) = 0 (2026-11-03)

### 한 줄 답
높이 같은 값(φ)에서 만든 화살표는 같은 곳을 빙빙 돌 수 없다. 한 바퀴 돌아 제자리에 오면 높이가 처음과 같아서, 돈 만큼 쌓이는 양이 없다.

### 그림으로 이해하기 (산 비유)
- **φ = 산의 높이**
- **경도 ∇φ** = 각 지점에서 가장 가파르게 올라가는 방향 화살표
- **회전 ∇×F** = 화살표들이 한 점 주위를 소용돌이처럼 얼마나 도는지

산에서 아무 길이나 한 바퀴 돌아 출발점으로 오면 높이 변화의 합은 항상 0이다.

$$\oint \nabla\varphi \cdot d\mathbf{l} = \varphi(\text{도착}) - \varphi(\text{출발}) = 0$$

스토크스 정리로 바꾸면

$$\oint \nabla\varphi \cdot d\mathbf{l} = \int (\nabla\times\nabla\varphi)\cdot d\mathbf{S} = 0$$

어떤 면을 잡아도 0이므로 회전 자체가 모든 곳에서 0이다.

### 계산으로 증명

$$\nabla\varphi = \left(\frac{\partial\varphi}{\partial x},\ \frac{\partial\varphi}{\partial y},\ \frac{\partial\varphi}{\partial z}\right)$$

$$(\nabla\times\nabla\varphi)_x = \frac{\partial^2\varphi}{\partial y\,\partial z} - \frac{\partial^2\varphi}{\partial z\,\partial y} = 0$$

편미분은 순서를 바꿔도 값이 같다(슈바르츠 정리) → 두 항이 지워진다. y, z 성분도 같다.
👉 핵심: **미분 순서를 바꿔도 같다 → 빼면 0**

### 전기에서 왜 중요한가

| 상황 | 식 | 의미 |
|---|---|---|
| 정전계 | E = −∇V → ∇×E = 0 | 전계가 경도라서 회전이 없음 → 보존장 |
| 보존장이면 | ∮E·dl = 0 | 어느 길로 옮겨도 한 일이 같음 → 전위(V)를 정의할 수 있음 |
| 시변 자계가 있을 때 | ∇×E = −∂B/∂t ≠ 0 | E를 ∇V 하나로 못 나타냄 (패러데이 법칙) |

**짝꿍 공식:** 회전의 발산도 0 → **∇·(∇×A) = 0** (그래서 ∇·B = 0이고 B = ∇×A로 쓸 수 있다)

## 2. 시간에 따라 변하는 전위와 자위 (2026-11-03)

### 정적 vs 시변

| | 정적 | 시변 |
|---|---|---|
| 자계 | B = ∇×A | B = ∇×A (같음) |
| 전계 | E = −∇V | **E = −∇V − ∂A/∂t** ⭐ |
| 전계의 회전 | ∇×E = 0 | ∇×E = −∂B/∂t ≠ 0 |

👉 시변일 때 전계에 **−∂A/∂t** 항이 하나 더 붙는다.

### 유도
1. ∇·B = 0이고 회전의 발산은 항상 0 → **B = ∇×A**
2. 패러데이 법칙에 넣기: ∇×E = −∂B/∂t = −∂(∇×A)/∂t → **∇×(E + ∂A/∂t) = 0**
3. 회전이 0인 벡터는 경도로 쓸 수 있다(1번 내용) → E + ∂A/∂t = −∇V

$$\boxed{\mathbf{E} = -\nabla V - \frac{\partial\mathbf{A}}{\partial t}}$$

- −∇V : 전하가 만드는 전계 (정전계 부분)
- −∂A/∂t : 변하는 자계가 만드는 전계 (유도 전계 부분)

### 로렌츠 게이지
A는 회전만 정해져 있고 발산은 정할 수 있다. 계산이 깔끔해지도록

$$\nabla\cdot\mathbf{A} = -\mu\varepsilon\frac{\partial V}{\partial t}$$

(정적이면 ∇·A = 0, 쿨롱 게이지)

### 파동방정식

$$\nabla^2 V - \mu\varepsilon\frac{\partial^2 V}{\partial t^2} = -\frac{\rho}{\varepsilon}$$

$$\nabla^2 \mathbf{A} - \mu\varepsilon\frac{\partial^2 \mathbf{A}}{\partial t^2} = -\mu\mathbf{J}$$

→ V와 A가 속도 **v = 1/√(με)** 로 퍼지는 파동. 진공에서는 빛의 속도 c.
(정적이면 포아송 방정식 ∇²V = −ρ/ε, ∇²A = −μJ)

### 지연 전위

$$V = \frac{1}{4\pi\varepsilon}\int \frac{\rho\,(t - R/v)}{R}\,dv$$

$$\mathbf{A} = \frac{\mu}{4\pi}\int \frac{\mathbf{J}\,(t - R/v)}{R}\,dv$$

거리 R만큼 떨어진 곳에는 영향이 **R/v 초 늦게** 도착한다 → "지연(retarded) 전위". (멀리서 돌을 던지면 물결이 조금 늦게 오는 것과 같다.)

### ✏️ 시험 대비 외울 것 4개
1. B = ∇×A
2. E = −∇V − ∂A/∂t
3. 로렌츠 조건 ∇·A = −με ∂V/∂t
4. 지연 시간 t − R/v, v = 1/√(με)
