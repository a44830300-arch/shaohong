## 1. 경도(기울기)의 회전은 왜 0인가 — ∇ × (∇φ) = 0 (2026-11-03)

### 한 줄 답
높이 같은 값(φ)에서 만든 화살표는 같은 곳을 빙빙 돌 수 없다. 한 바퀴 돌아 제자리에 오면 높이가 처음과 같아서, 돈 만큼 쌓이는 양이 없다.

### 그림으로 이해하기 (산 비유)
- **φ = 산의 높이**
- **경도 ∇φ** = 각 지점에서 가장 가파르게 올라가는 방향 화살표
- **회전 ∇×F** = 화살표들이 한 점 주위를 소용돌이처럼 얼마나 도는지

산에서 아무 길이나 한 바퀴 돌아 출발점으로 오면 높이 변화의 합은 항상 0이다.

$$\oint \nabla\varphi \cdot d\mathbf{l} = \varphi(\text{도착}) - \varphi(\text{출발}) = 0$$

스토크스 정리로 바꾸면

$$\oint \nabla\varphi \cdot d\mathbf{l} = \int (\nabla\times\nabla\varphi)\cdot d\mathbf{S} = 0$$

어떤 면을 잡아도 0이므로 회전 자체가 모든 곳에서 0이다.

### 계산으로 증명

$$\nabla\varphi = \left(\frac{\partial\varphi}{\partial x},\ \frac{\partial\varphi}{\partial y},\ \frac{\partial\varphi}{\partial z}\right)$$

$$(\nabla\times\nabla\varphi)_x = \frac{\partial^2\varphi}{\partial y\,\partial z} - \frac{\partial^2\varphi}{\partial z\,\partial y} = 0$$

편미분은 순서를 바꿔도 값이 같다(슈바르츠 정리) → 두 항이 지워진다. y, z 성분도 같다.
👉 핵심: **미분 순서를 바꿔도 같다 → 빼면 0**

### 전기에서 왜 중요한가

| 상황 | 식 | 의미 |
|---|---|---|
| 정전계 | E = −∇V → ∇×E = 0 | 전계가 경도라서 회전이 없음 → 보존장 |
| 보존장이면 | ∮E·dl = 0 | 어느 길로 옮겨도 한 일이 같음 → 전위(V)를 정의할 수 있음 |
| 시변 자계가 있을 때 | ∇×E = −∂B/∂t ≠ 0 | E를 ∇V 하나로 못 나타냄 (패러데이 법칙) |

**짝꿍 공식:** 회전의 발산도 0 → **∇·(∇×A) = 0** (그래서 ∇·B = 0이고 B = ∇×A로 쓸 수 있다)

## 2. 시간에 따라 변하는 전위와 자위 (2026-11-03)

### 정적 vs 시변

| | 정적 | 시변 |
|---|---|---|
| 자계 | B = ∇×A | B = ∇×A (같음) |
| 전계 | E = −∇V | **E = −∇V − ∂A/∂t** ⭐ |
| 전계의 회전 | ∇×E = 0 | ∇×E = −∂B/∂t ≠ 0 |

👉 시변일 때 전계에 **−∂A/∂t** 항이 하나 더 붙는다.

### 유도
1. ∇·B = 0이고 회전의 발산은 항상 0 → **B = ∇×A**
2. 패러데이 법칙에 넣기: ∇×E = −∂B/∂t = −∂(∇×A)/∂t → **∇×(E + ∂A/∂t) = 0**
3. 회전이 0인 벡터는 경도로 쓸 수 있다(1번 내용) → E + ∂A/∂t = −∇V

$$\boxed{\mathbf{E} = -\nabla V - \frac{\partial\mathbf{A}}{\partial t}}$$

- −∇V : 전하가 만드는 전계 (정전계 부분)
- −∂A/∂t : 변하는 자계가 만드는 전계 (유도 전계 부분)

### 로렌츠 게이지
A는 회전만 정해져 있고 발산은 정할 수 있다. 계산이 깔끔해지도록

$$\nabla\cdot\mathbf{A} = -\mu\varepsilon\frac{\partial V}{\partial t}$$

(정적이면 ∇·A = 0, 쿨롱 게이지)

### 파동방정식

$$\nabla^2 V - \mu\varepsilon\frac{\partial^2 V}{\partial t^2} = -\frac{\rho}{\varepsilon}$$

$$\nabla^2 \mathbf{A} - \mu\varepsilon\frac{\partial^2 \mathbf{A}}{\partial t^2} = -\mu\mathbf{J}$$

→ V와 A가 속도 **v = 1/√(με)** 로 퍼지는 파동. 진공에서는 빛의 속도 c.
(정적이면 포아송 방정식 ∇²V = −ρ/ε, ∇²A = −μJ)

### 지연 전위

$$V = \frac{1}{4\pi\varepsilon}\int \frac{\rho\,(t - R/v)}{R}\,dv$$

$$\mathbf{A} = \frac{\mu}{4\pi}\int \frac{\mathbf{J}\,(t - R/v)}{R}\,dv$$

거리 R만큼 떨어진 곳에는 영향이 **R/v 초 늦게** 도착한다 → "지연(retarded) 전위". (멀리서 돌을 던지면 물결이 조금 늦게 오는 것과 같다.)

### ✏️ 시험 대비 외울 것 4개
1. B = ∇×A
2. E = −∇V − ∂A/∂t
3. 로렌츠 조건 ∇·A = −με ∂V/∂t
4. 지연 시간 t − R/v, v = 1/√(με)

## 3. 파동방정식의 해 (2026-11-03)

### 풀 식 (전하·전류가 없는 곳)

$$\nabla^2\psi - \frac{1}{v^2}\frac{\partial^2\psi}{\partial t^2} = 0, \qquad v = \frac{1}{\sqrt{\mu\varepsilon}}$$

z 방향 한 줄(1차원)만 보면

$$\frac{\partial^2\psi}{\partial z^2} = \frac{1}{v^2}\frac{\partial^2\psi}{\partial t^2}$$

### ① 일반해 (달랑베르 해)

$$\boxed{\psi(z,t) = f(z - vt) + g(z + vt)}$$

- **f(z − vt)** : +z 방향으로 속도 v로 가는 파 (진행파)
- **g(z + vt)** : −z 방향으로 가는 파 (반사파·후진파)
- f, g는 **아무 모양이나 된다.** 모양은 그대로 두고 미끄러지듯 이동한다.

**맞는지 확인:** u = z − vt로 두면 ∂²f/∂z² = f″, ∂²f/∂t² = v²f″ → 넣으면 양쪽이 같다.

**방향 읽는 법:** 괄호 안 값이 일정하게 유지되려면, z − vt에서는 t가 커질 때 z도 커져야 한다 → +z 방향. 부호가 **다르면(−) +방향, 같으면(+) −방향.**

### ② 정현파 해 (시험에 제일 많이 나옴)

$$\psi = A\cos(\omega t - \beta z)$$

| 기호 | 이름 | 식 |
|---|---|---|
| ω | 각주파수 | ω = 2πf |
| β | 위상정수 | β = ω/v = ω√(με) = 2π/λ |
| v | 위상속도 | v = ω/β = fλ |
| λ | 파장 | λ = 2π/β = v/f |

### ③ 페이저(복소수)로 쓰면 — 헬름홀츠 방정식
시간 미분 ∂/∂t → jω 로 바뀌어서

$$\nabla^2 E + \beta^2 E = 0$$

$$E(z) = E^{+}e^{-j\beta z} + E^{-}e^{+j\beta z}$$

- e^{−jβz} : +z 방향 파, e^{+jβz} : −z 방향 파

**손실 있는 매질:** β 대신 전파정수 **γ = α + jβ** → E = E₀ e^{−αz} e^{−jβz}. α(감쇠정수) 때문에 가면서 점점 작아진다.

### ④ 구면파 (점에서 사방으로 퍼질 때)

$$\psi = \frac{f(t - r/v)}{r}$$

멀어질수록 1/r로 작아지고, r/v만큼 늦게 도착 → **2번의 지연 전위와 같은 모양.**

### 함께 외울 것: 고유 임피던스
평면파에서 전계와 자계의 비

$$\eta = \frac{E}{H} = \sqrt{\frac{\mu}{\varepsilon}}, \qquad \text{진공: } \eta_0 = 120\pi \approx 377\,\Omega$$

### ✏️ 예제
진공에서 E = 10cos(2π×10⁸ t − βz) [V/m]일 때
- f = 10⁸ Hz = 100 MHz
- v = c = 3×10⁸ m/s
- λ = v/f = **3 m**
- β = 2π/λ = **2π/3 rad/m**
- 방향: −βz 부호가 ωt와 다름 → **+z 방향**
- H 크기 = 10/377 ≈ **0.0265 A/m**

## 4. 제주는 왜 발전량과 사용량을 매 순간 맞춰야 할까 — 60Hz 주파수 (2026-11-16)

> 질문: "제주는 섬이라 만드는 전기와 쓰는 전기를 매 순간 맞춰야 한다. 어긋나면 60Hz 주파수가 흔들리고, 심하면 정전이 날 수 있다." — 이유?

### ① 주파수 = 발전기가 도는 속도
발전기(동기발전기)는 빙글빙글 돌면서 교류를 만든다. 도는 속도가 곧 주파수다.

$$f = \frac{P \cdot N}{120} \quad (P: 극수,\ N: 회전수[rpm])$$

예) 2극 발전기가 3600 rpm으로 돌면 f = 2×3600/120 = **60 Hz**

### ② 만드는 힘 vs 쓰는 힘 = 줄다리기
- 터빈이 발전기를 **미는 힘**(기계 입력) ↔ 전기를 쓰는 쪽이 발전기를 **잡아당기는 힘**(전기 부하)
- **쓰는 전기 > 만드는 전기** → 모자란 만큼 발전기의 회전 에너지를 꺼내 씀 → 발전기가 **느려짐** → 주파수 ↓ (60 → 59.x Hz)
- **만드는 전기 > 쓰는 전기** → 남는 힘이 발전기를 더 돌림 → **빨라짐** → 주파수 ↑
- 그래서 주파수가 60Hz면 "딱 맞음", 흔들리면 "어긋남"의 신호다.

$$P_{기계} - P_{전기} = \frac{d}{dt}\left(\frac{1}{2}J\omega^2\right) \quad (J: 관성모멘트)$$

### ③ 왜 하필 섬(제주)이 더 힘들까
| 이유 | 설명 |
|---|---|
| 계통이 작다 | 육지는 발전기가 아주 많아서 한 곳이 흔들려도 다 같이 버텨 준다. 제주는 발전기 수가 적어 작은 어긋남에도 크게 흔들린다. |
| 관성(J)이 작다 | 무거운 발전기가 많이 돌수록 속도가 잘 안 변한다(무거운 팽이). 제주는 돌아가는 덩어리가 적어 주파수가 빨리 변한다. |
| 육지와 따로 논다 | 육지와 해저 케이블(HVDC, 직류)로 이어져 있지만 직류라서 육지 발전기의 관성을 그대로 나눠 받지 못한다. |
| 태양광·풍력이 많다 | 햇빛·바람에 따라 발전량이 수시로 바뀐다. 또 인버터로 연결돼 돌아가는 덩어리(관성)가 없다. → 그래서 제주는 전기가 남으면 풍력·태양광 **출력제어**(발전을 강제로 멈춤)를 자주 한다. |

### ④ 왜 정전까지 갈까 (연쇄 반응)
1. 주파수가 정해진 범위를 벗어남
2. 발전기·설비를 지키려고 보호계전기가 발전기를 **자동으로 끊음**(트립)
3. 발전기가 빠지면 공급이 더 모자람 → 주파수 더 떨어짐
4. 막으려고 일부 지역 전기를 일부러 끊음(저주파 부하차단, UFLS)
5. 그래도 못 막으면 줄줄이 끊겨 **대정전(블랙아웃)**

### 한 줄 정리
**주파수는 발전기 속도이고, 속도는 "만드는 힘 − 쓰는 힘"으로 정해진다. 제주는 작고·가볍고·따로 놀고·변덕스러운 재생에너지가 많아서 조금만 어긋나도 크게 흔들린다.**
