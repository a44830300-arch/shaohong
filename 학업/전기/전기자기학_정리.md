크리링과 공부하며 물어본 내용을 모아 둔 노트. 새 질문을 하면 아래에 계속 더한다.

## 1. 경도(기울기)의 회전은 왜 0인가 — ∇ × (∇φ) = 0 (2026-11-03)

### 한 줄 답
높이 같은 값(φ)에서 만든 화살표는 같은 곳을 빙빙 돌 수 없다. 한 바퀴 돌아 제자리에 오면 높이가 처음과 같아서, 돈 만큼 쌓이는 양이 없다.

### 그림으로 이해하기 (산 비유)
- **φ = 산의 높이**
- **경도 ∇φ** = 각 지점에서 가장 가파르게 올라가는 방향 화살표
- **회전 ∇×F** = 화살표들이 한 점 주위를 소용돌이처럼 얼마나 도는지

산에서 아무 길이나 한 바퀴 돌아 출발점으로 오면 높이 변화의 합은 항상 0이다.

$$\oint \nabla\varphi \cdot d\mathbf{l} = \varphi(\text{도착}) - \varphi(\text{출발}) = 0$$

스토크스 정리로 바꾸면

$$\oint \nabla\varphi \cdot d\mathbf{l} = \int (\nabla\times\nabla\varphi)\cdot d\mathbf{S} = 0$$

어떤 면을 잡아도 0이므로 회전 자체가 모든 곳에서 0이다.

### 계산으로 증명

$$\nabla\varphi = \left(\frac{\partial\varphi}{\partial x},\ \frac{\partial\varphi}{\partial y},\ \frac{\partial\varphi}{\partial z}\right)$$

$$(\nabla\times\nabla\varphi)_x = \frac{\partial^2\varphi}{\partial y\,\partial z} - \frac{\partial^2\varphi}{\partial z\,\partial y} = 0$$

편미분은 순서를 바꿔도 값이 같다(슈바르츠 정리) → 두 항이 지워진다. y, z 성분도 같다.
👉 핵심: **미분 순서를 바꿔도 같다 → 빼면 0**

### 전기에서 왜 중요한가

| 상황 | 식 | 의미 |
|---|---|---|
| 정전계 | E = −∇V → ∇×E = 0 | 전계가 경도라서 회전이 없음 → 보존장 |
| 보존장이면 | ∮E·dl = 0 | 어느 길로 옮겨도 한 일이 같음 → 전위(V)를 정의할 수 있음 |
| 시변 자계가 있을 때 | ∇×E = −∂B/∂t ≠ 0 | E를 ∇V 하나로 못 나타냄 (패러데이 법칙) |

**짝꿍 공식:** 회전의 발산도 0 → **∇·(∇×A) = 0** (그래서 ∇·B = 0이고 B = ∇×A로 쓸 수 있다)

## 2. 시간에 따라 변하는 전위와 자위 (2026-11-03)

### 정적 vs 시변

| | 정적 | 시변 |
|---|---|---|
| 자계 | B = ∇×A | B = ∇×A (같음) |
| 전계 | E = −∇V | **E = −∇V − ∂A/∂t** ⭐ |
| 전계의 회전 | ∇×E = 0 | ∇×E = −∂B/∂t ≠ 0 |

👉 시변일 때 전계에 **−∂A/∂t** 항이 하나 더 붙는다.

### 유도
1. ∇·B = 0이고 회전의 발산은 항상 0 → **B = ∇×A**
2. 패러데이 법칙에 넣기: ∇×E = −∂B/∂t = −∂(∇×A)/∂t → **∇×(E + ∂A/∂t) = 0**
3. 회전이 0인 벡터는 경도로 쓸 수 있다(1번 내용) → E + ∂A/∂t = −∇V

$$\boxed{\mathbf{E} = -\nabla V - \frac{\partial\mathbf{A}}{\partial t}}$$

- −∇V : 전하가 만드는 전계 (정전계 부분)
- −∂A/∂t : 변하는 자계가 만드는 전계 (유도 전계 부분)

### 로렌츠 게이지
A는 회전만 정해져 있고 발산은 정할 수 있다. 계산이 깔끔해지도록

$$\nabla\cdot\mathbf{A} = -\mu\varepsilon\frac{\partial V}{\partial t}$$

(정적이면 ∇·A = 0, 쿨롱 게이지)

### 파동방정식

$$\nabla^2 V - \mu\varepsilon\frac{\partial^2 V}{\partial t^2} = -\frac{\rho}{\varepsilon}$$

$$\nabla^2 \mathbf{A} - \mu\varepsilon\frac{\partial^2 \mathbf{A}}{\partial t^2} = -\mu\mathbf{J}$$

→ V와 A가 속도 **v = 1/√(με)** 로 퍼지는 파동. 진공에서는 빛의 속도 c.
(정적이면 포아송 방정식 ∇²V = −ρ/ε, ∇²A = −μJ)

### 지연 전위

$$V = \frac{1}{4\pi\varepsilon}\int \frac{\rho\,(t - R/v)}{R}\,dv$$

$$\mathbf{A} = \frac{\mu}{4\pi}\int \frac{\mathbf{J}\,(t - R/v)}{R}\,dv$$

거리 R만큼 떨어진 곳에는 영향이 **R/v 초 늦게** 도착한다 → "지연(retarded) 전위". (멀리서 돌을 던지면 물결이 조금 늦게 오는 것과 같다.)

### ✏️ 시험 대비 외울 것 4개
1. B = ∇×A
2. E = −∇V − ∂A/∂t
3. 로렌츠 조건 ∇·A = −με ∂V/∂t
4. 지연 시간 t − R/v, v = 1/√(με)

## 3. 파동방정식의 해 (2026-11-03)

### 풀 식 (전하·전류가 없는 곳)

$$\nabla^2\psi - \frac{1}{v^2}\frac{\partial^2\psi}{\partial t^2} = 0, \qquad v = \frac{1}{\sqrt{\mu\varepsilon}}$$

z 방향 한 줄(1차원)만 보면

$$\frac{\partial^2\psi}{\partial z^2} = \frac{1}{v^2}\frac{\partial^2\psi}{\partial t^2}$$

### ① 일반해 (달랑베르 해)

$$\boxed{\psi(z,t) = f(z - vt) + g(z + vt)}$$

- **f(z − vt)** : +z 방향으로 속도 v로 가는 파 (진행파)
- **g(z + vt)** : −z 방향으로 가는 파 (반사파·후진파)
- f, g는 **아무 모양이나 된다.** 모양은 그대로 두고 미끄러지듯 이동한다.

**맞는지 확인:** u = z − vt로 두면 ∂²f/∂z² = f″, ∂²f/∂t² = v²f″ → 넣으면 양쪽이 같다.

**방향 읽는 법:** 괄호 안 값이 일정하게 유지되려면, z − vt에서는 t가 커질 때 z도 커져야 한다 → +z 방향. 부호가 **다르면(−) +방향, 같으면(+) −방향.**

### ② 정현파 해 (시험에 제일 많이 나옴)

$$\psi = A\cos(\omega t - \beta z)$$

| 기호 | 이름 | 식 |
|---|---|---|
| ω | 각주파수 | ω = 2πf |
| β | 위상정수 | β = ω/v = ω√(με) = 2π/λ |
| v | 위상속도 | v = ω/β = fλ |
| λ | 파장 | λ = 2π/β = v/f |

### ③ 페이저(복소수)로 쓰면 — 헬름홀츠 방정식
시간 미분 ∂/∂t → jω 로 바뀌어서

$$\nabla^2 E + \beta^2 E = 0$$

$$E(z) = E^{+}e^{-j\beta z} + E^{-}e^{+j\beta z}$$

- e^{−jβz} : +z 방향 파, e^{+jβz} : −z 방향 파

**손실 있는 매질:** β 대신 전파정수 **γ = α + jβ** → E = E₀ e^{−αz} e^{−jβz}. α(감쇠정수) 때문에 가면서 점점 작아진다.

### ④ 구면파 (점에서 사방으로 퍼질 때)

$$\psi = \frac{f(t - r/v)}{r}$$

멀어질수록 1/r로 작아지고, r/v만큼 늦게 도착 → **2번의 지연 전위와 같은 모양.**

### 함께 외울 것: 고유 임피던스
평면파에서 전계와 자계의 비

$$\eta = \frac{E}{H} = \sqrt{\frac{\mu}{\varepsilon}}, \qquad \text{진공: } \eta_0 = 120\pi \approx 377\,\Omega$$

### ✏️ 예제
진공에서 E = 10cos(2π×10⁸ t − βz) [V/m]일 때
- f = 10⁸ Hz = 100 MHz
- v = c = 3×10⁸ m/s
- λ = v/f = **3 m**
- β = 2π/λ = **2π/3 rad/m**
- 방향: −βz 부호가 ωt와 다름 → **+z 방향**
- H 크기 = 10/377 ≈ **0.0265 A/m**

## 4. 제주는 왜 발전량과 사용량을 매 순간 맞춰야 할까 — 60Hz 주파수 (2026-11-16)

> 질문: "제주는 섬이라 만드는 전기와 쓰는 전기를 매 순간 맞춰야 한다. 어긋나면 60Hz 주파수가 흔들리고, 심하면 정전이 날 수 있다." — 이유?

### ① 주파수 = 발전기가 도는 속도
발전기(동기발전기)는 빙글빙글 돌면서 교류를 만든다. 도는 속도가 곧 주파수다.

$$f = \frac{P \cdot N}{120} \quad (P: 극수,\ N: 회전수[rpm])$$

예) 2극 발전기가 3600 rpm으로 돌면 f = 2×3600/120 = **60 Hz**

### ② 만드는 힘 vs 쓰는 힘 = 줄다리기
- 터빈이 발전기를 **미는 힘**(기계 입력) ↔ 전기를 쓰는 쪽이 발전기를 **잡아당기는 힘**(전기 부하)
- **쓰는 전기 > 만드는 전기** → 모자란 만큼 발전기의 회전 에너지를 꺼내 씀 → 발전기가 **느려짐** → 주파수 ↓ (60 → 59.x Hz)
- **만드는 전기 > 쓰는 전기** → 남는 힘이 발전기를 더 돌림 → **빨라짐** → 주파수 ↑
- 그래서 주파수가 60Hz면 "딱 맞음", 흔들리면 "어긋남"의 신호다.

$$P_{기계} - P_{전기} = \frac{d}{dt}\left(\frac{1}{2}J\omega^2\right) \quad (J: 관성모멘트)$$

### ③ 왜 하필 섬(제주)이 더 힘들까
| 이유 | 설명 |
|---|---|
| 계통이 작다 | 육지는 발전기가 아주 많아서 한 곳이 흔들려도 다 같이 버텨 준다. 제주는 발전기 수가 적어 작은 어긋남에도 크게 흔들린다. |
| 관성(J)이 작다 | 무거운 발전기가 많이 돌수록 속도가 잘 안 변한다(무거운 팽이). 제주는 돌아가는 덩어리가 적어 주파수가 빨리 변한다. |
| 육지와 따로 논다 | 육지와 해저 케이블(HVDC, 직류)로 이어져 있지만 직류라서 육지 발전기의 관성을 그대로 나눠 받지 못한다. |
| 태양광·풍력이 많다 | 햇빛·바람에 따라 발전량이 수시로 바뀐다. 또 인버터로 연결돼 돌아가는 덩어리(관성)가 없다. → 그래서 제주는 전기가 남으면 풍력·태양광 **출력제어**(발전을 강제로 멈춤)를 자주 한다. |

### ④ 왜 정전까지 갈까 (연쇄 반응)
1. 주파수가 정해진 범위를 벗어남
2. 발전기·설비를 지키려고 보호계전기가 발전기를 **자동으로 끊음**(트립)
3. 발전기가 빠지면 공급이 더 모자람 → 주파수 더 떨어짐
4. 막으려고 일부 지역 전기를 일부러 끊음(저주파 부하차단, UFLS)
5. 그래도 못 막으면 줄줄이 끊겨 **대정전(블랙아웃)**

### 한 줄 정리
**주파수는 발전기 속도이고, 속도는 "만드는 힘 − 쓰는 힘"으로 정해진다. 제주는 작고·가볍고·따로 놀고·변덕스러운 재생에너지가 많아서 조금만 어긋나도 크게 흔들린다.**

## 2026-11-19 · 10조 종합보고서 「제주도 분산에너지 정책의 적용과 난항」 문단별 쉬운 설명

(원본: 카카오톡 받은 파일 `제주도_분산에너지_정책_종합보고서.hwp`, 제출 2026-11-16)

### Ⅰ. 서론
- **1문단 (분산에너지가 뭐야?)** 큰 발전소에서 멀리 보내는 전기 말고, **쓰는 곳 근처에서 만드는 전기**. 법은 "발전소 크기 40MW 이하"를 기준으로 삼지만, 집·건물 자가용 설비 등은 따로 정해서 "40MW 이하 재생에너지 = 분산에너지"라고 딱 잘라 말할 수는 없다.
- **2문단 (왜 제주가 문제야?)** 전기는 만드는 양 = 쓰는 양이 늘 같아야 주파수(60Hz)가 안 흔들린다. 제주는 태양광·풍력이 빠르게 늘어서 날씨 좋은 날 전기가 남고 → 발전을 강제로 멈추는 **출력제어**가 2015년 3번 → 2023년 181번. 육지로 보내는 해저 케이블(HVDC)도 한계가 있어서 **제주에서 만든 건 제주에서 저장·소비(지산지소)**하는 구조가 필요하다.
- **3문단 (보고서 목적)** 특별법 2024.6 시행, 제주는 2025.11 분산에너지 특화지역(특구) 지정. 이 정책의 효과·한계를 법·연구·사례(성읍1리, 가파도)로 살펴보고 개선 방향을 낸다.

### Ⅱ-1. 특별법과 제주
- **1문단** 특별법 핵심 3가지: ① 특구 = 새 사업을 규제 풀어 시험하는 곳 ② 특구 안에서 40MW 이하 사업자는 **한전을 거치지 않고 손님에게 전기를 바로 팔 수 있음(직접거래)** ③ 지역마다 전기요금을 다르게 할 근거(제45조).
- **2문단** 제주는 2024.6부터 실시간시장·재생에너지 입찰제도를 시범 운영 → 출력제어 181번 → 83번으로 줄었다. 하지만 날씨, 운영 기준, 세는 방식 변화도 있었으니 **"제도 덕분"이라고 단정하면 안 된다**.

### Ⅱ-2. 남는 전기를 다루는 기술 4가지와 한계
- **기술 소개** P2H(전기→열), VPP(가상발전소), 플러스 DR(남을 때 전기차 충전), V2G(전기차→전력망으로 다시 보내기).
- **P2H** 남는 전기로 물을 데워 둔다(커다란 전기 보온물통). 문제: 봄·가을엔 따뜻한 물이 별로 필요 없음 → 온실·호텔처럼 늘 열을 쓰는 곳이 없으면 본전 못 뽑는다.
- **표** 4가지 기술의 역할과 걱정거리 요약(아래 문단들과 같은 내용).
- **VPP** 흩어진 작은 태양광·배터리를 인터넷으로 묶어 **큰 발전소 하나처럼** 시장에 참여. 문제: 내일 발전량 예측이 틀리면 벌금처럼 돈이 깎임 → 작은 회사는 위험. 또 설비 늘리기보다 **시장 규칙·수요 쪽 대응**이 출력제어 줄이는 데 더 중요했다.
- **플러스 DR** 전기가 남는 낮(10~15시)에 전기차 충전하도록 유도. 제주 전기차 주인 313명 조사: 하루 전에 알려 주면 kWh당 71원이면 참여, 3시간 전 급히 알리면 89원 필요. 안 하겠다는 사람도 21% → 31%. **미리 알려 주고 돈을 충분히 줘야 참여한다.**
- **V2G** 전기차 배터리를 "움직이는 보조배터리"로 써서 전기 부족할 때 망에 돌려줌. 문제: 배터리 빨리 닳음, 제조사 보증 문제, 양방향 충전기 비쌈, 돌려준 전기 값 계산 규칙이 없음.

### Ⅱ-3. 직접거래의 조건과 배터리 비용 — 이중고
- **1문단** 흔한 오해: "쓰는 전기의 70%만 직접 만들면 된다." 실제 규칙은 더 빡세다.
- **2문단** 사업자는 손님이 1년간 쓰는 전기 **100%를 책임**지고 공급(모자라면 시장·한전에서 사 와서라도). 그리고 자기가 만든 게 **70% 안 되면 추가 요금**을 물 수 있다. (비유: 도시락 가게가 100인분을 무조건 대야 하고, 직접 만든 게 70인분 미만이면 벌금)
- **표** 100% 공급 의무 / 70% 미만 추가요금 / 처음 3년·점검 기간(연 60일)은 면제 가능 / 한전 전선 쓰면 사용료 → 날씨 나쁘면 비싸게 사 와야 하고, 3년 후 추가요금 위험을 미리 계산해야 한다.
- **ESS·BESS 문단** ESS = 전기 저장장치 전체, BESS = 그중 배터리형(제주 주력). 70% 채우고 낮 전기를 밤에 쓰려면 큰 배터리를 같이 달아야 하는 압박이 생긴다.
- **효과 문단** 계획된 배터리를 다 지으면 2038년 출력제한율 11.0% → 5.1%로 줄어든다(효과 있음).
- **부작용 문단** 그런데 모든 작은 사업장에 배터리를 강제하면 설치비 + 10~15년마다 교체 + 화재 대비 비용 때문에 **직접거래 전기값이 한전보다 비싸지는 역전**이 생긴다.

### Ⅱ-4. 지역별 차등 전기요금과 제주 제외 문제
- **1문단** 발전소 가까운 곳은 송전 비용이 적으니 요금을 싸게 하자는 제도. 2026.8.26 정부·한전이 공장용(산업용) 고압 전기부터 적용하는 초안 발표.
- **표** 비수도권 공장 전기요금 최대 10% 인하, 그런데 **제주는 아예 빠짐**. 아직 확정 전(공청회 단계).
- **2문단** 제외 이유: 섬이라 구조가 특수하고 해저 케이블 비용 계산이 복잡해서. 결과: 다른 지역 공장은 싸지는데 제주 공장은 그대로 → 경쟁력 약화. 제주가 출력제어 고생을 제일 먼저 하며 실험 비용을 감당했는데 혜택에서 빠져 **반발**이 크다.

### Ⅱ-5. 제주 집 전기 시간대별 요금(TOU) 실험
- **1문단** 지역별 요금은 "어디냐"로, TOU는 **"몇 시냐"로** 값을 다르게 한다(심야 택시 할증처럼). 제주가 2021.9 전국 최초로 집에 시범 도입.
- **2문단** 결과: 고른 집이 거의 없음. 한 달에 500~600kWh 이상 써야 이득인데 보통 집은 그보다 적게 쓰고, 저녁(16~22시, 비싼 시간)에 전기를 많이 써서 **오히려 요금이 오른다**.
- **3문단** 성읍1리 태양광 30가구 사업도 같다. 낮에 만든 전기를 배터리·히트펌프·전기차 충전으로 옮기지 못하고 밤에 계속 쓰면 이득이 반으로 준다. → 낮(태양광 많은 때) 요금을 확 낮추고 스마트 가전과 묶은 **"제주 맞춤형 요금제"**로 바뀌어야 한다.

### Ⅲ-1. 확인된 한계 (결론)
70% 추가요금 위험, 배터리 투자 부담, 수요반응 보상 부족, 산업용 요금제에서 제주 제외. 성읍1리는 주민 동의·이익 나누기, 가파도는 설치 후 고장 관리·돈 마련이 숙제. 도가 이전 계획(제6차)을 평가하며 말한 "양만 늘리고, 쓰는 쪽 변화·주민 갈등·실행 체계가 부족"하다는 문제가 아직 그대로다.

### Ⅲ-2. 개선 방향 3가지
1. **섬에 맞게 규칙·요금 고치기** — 직접거래 조건 완화, 3년 면제 후에도 안전장치, 요금제 제외에 대한 보완책.
2. **작은 사업장 끝까지 관리** — 가파도처럼 고장·부품 부족으로 철거되지 않게 주인·관리 책임을 한 곳으로, 유지보수 적립금 의무화. 220억 원 RE100 후속 사업도 10년 이상 관리 계획 검증.
3. **여러 기술 섞어 쓰기** — 배터리만 늘리면 갈수록 효과 대비 비용이 커짐 → P2H·VPP·DR·V2G 조합. V2G는 충전기 지원·배터리 손상 보상·전기값 정산 규칙 마련. 마을 사업은 참여·안 참여 가구 사이 이익 나누는 기준을 미리 정하기.

### Ⅲ-3. 기대되는 모습
- **1문단** 제7차 계획(2026~2030)은 "설비 늘리기"에서 "제대로 돌아가게 하기"로 바뀌는 중. 저장·열·전기차·VPP + 주민 이익 나누기를 합치면 출력제어가 줄고 아낀 돈·수익이 도민에게 돌아가는 모델이 될 수 있다. 단, 기술만으론 안 되고 제도·맞춤 요금·정당한 보상이 함께 있어야 한다.
- **2문단** 앞으로 성공 여부는 "발전소를 얼마나 지었나"가 아니라 **잘 관리되나, 주민이 참여하나, 이익이 지역에 남나**로 봐야 한다.

### 한 줄 정리
**제주는 재생에너지가 남아서 버리는 섬. 법으로 "직접 팔기·지역 요금" 길은 열었지만, 70% 규칙·비싼 배터리·약한 보상·요금 혜택 제외 때문에 현장에선 잘 안 굴러간다. 섬에 맞게 규칙을 고치고, 끝까지 관리하고, 여러 기술을 섞고, 주민에게 이익이 돌아가야 한다.**

## 분산에너지 활성화 특별법 — 특화지역·직접거래·지역별 요금 말고 나머지 (2026-11-23)

> ✅ 2026-11-23 검색으로 확인함(산업부 보도자료·신김 뉴스레터·프레시안, 주로 2023~2024 자료). "확인 필요"만 아직 원문 확인 전. 그 뒤 개정 여부는 국가법령정보센터(law.go.kr)로 확인.

- **법을 만든 이유:** 큰 발전소(지방·바닷가) → 긴 송전선 → 수도권으로 보내는 구조를 **쓰는 곳 가까이에서 만들어 쓰는 구조**로 바꾸려고. 송전탑 갈등(밀양 등), 수도권에 전기 수요가 몰리는 문제가 배경.
- **분산에너지란(정의):** 쓰는 곳 가까이에서 만드는 작은 규모 에너지. 시행령 기준 **40MW 이하 모든 발전설비 + 500MW 이하 집단에너지 발전설비**(집단에너지는 15km 이내 송전선 연계 등 조건). ESS·DR 포함 여부는 확인 필요.
- **기본계획:** 산업부 장관이 **5년마다 분산에너지 활성화 기본계획**을 세운다. 실태조사를 거쳐 세움. 시·도 계획은 검색으로 확인 못 함(확인 필요).
- **분산에너지 설치 의무:** 전기를 많이 쓰는 **새 건물·대규모 개발사업**은 쓰는 전기의 일부를 분산에너지(태양광 등)로 마련해야 한다. 대상: **연 20만MWh 이상 전력사용시설, 100만㎡ 이상 도시개발사업**(산업단지 관리자는 제외). 얼마나 설치할지는 고시로 정함.
- **전력계통영향평가:** 전기를 아주 많이 쓰는 시설(예: 데이터센터)이 들어설 때 그 지역 전력망이 버틸 수 있는지 **미리 평가받게** 한다(대상: **계약전력 10MW 이상**, 전국) → 수도권 쏠림을 막고 발전소가 많은 지방으로 오게 유도. 제주처럼 전기가 남는 곳에는 오히려 기회(전기 많이 쓰는 시설 유치) 논리로 쓸 수 있다(크리링 판단).
- **새 사업 인정:** 법이 '분산에너지사업'으로 **통합발전소사업(VPP)**, 연료전지·수소발전사업, 저장전기판매사업, 재생에너지전기공급사업(PPA), 소규모전력중개사업 등을 정함 → 흩어진 태양광·배터리를 묶어 전력시장에 팔 수 있다.
- **배전망 관리:** 배전사업자(한전)가 분산에너지 연결·관리 책임을 진다는 내용은 검색으로 확인 못 함(확인 필요).
- **지원:** 이름은 **분산에너지 진흥센터**(한국에너지공단·전력거래소), 지자체에 특화지역 신청 컨설팅. 보조·융자 근거는 시행령에 있음.
- **논란:** 분산에너지 범위에 **중소형 원자로(SMR)**도 들어감. 입법예고 때는 모듈당 300MW 이하였는데 시행령에서 **500MW 이하로 넓어져** "500MW 이하면 화석·원자력도 다 분산이냐" 비판이 나왔다.
- **특화지역 보충:** 제33조에 따라 지자체장 신청 → 에너지위원회 심의 → 산업부 지정. 직접거래는 정확히는 "**전력시장을 거치지 않고**" 사용자에게 바로 공급하는 특례. 2024년 8월 제주·울릉도·흑산도를 특화지역으로 먼저 지정하게 하는 개정안이 발의됨(통과 여부 확인 필요).
- **지역별 요금(제45조) 보충:** 송배전 거리·전력 자급률·분산에너지 사용률을 고려해 요금을 다르게. 정부는 도매가격을 지역별로 다르게 하는 '지역별 한계가격제'부터 도입하겠다고 함. 제45조 번호는 법률안 단계 자료로만 확인(최종 조문 번호 확인 필요).

## 지산지소와 분산에너지는 어떻게 이어지나? (2026-11-23 질문)

- **한 줄로:** 지산지소는 **목표(어떻게 되고 싶은가)**, 분산에너지는 **방법(무엇으로 하나)**, 특별법은 **규칙(해도 되게 만든 판)**.
  - 지산지소 = "그 지역에서 만든 전기를 그 지역에서 쓴다"는 **원칙**
  - 분산에너지 = 쓰는 곳 가까이에서 만드는 **작은 발전·저장 설비**(태양광·풍력·ESS·전기차·열·VPP)
  - 분산에너지 특별법 = 그걸 실제로 굴릴 수 있게 한 **제도**(특화지역·직접거래·지역별 요금)
- **연결 흐름 (발표용 순서):**
  1. 예전: 큰 발전소 → 긴 송전선 → 먼 도시(중앙집중). 만드는 곳 ≠ 쓰는 곳.
  2. 분산에너지는 만드는 곳을 쓰는 곳 가까이로 옮긴다 → **"지산"(지역에서 만든다)**까지는 해결.
  3. 그런데 제주는 만들기만 하고 못 써서 버린다(출력제어 2023년 181번, 해저케이블로 보내는 것도 한계) → **"지소"(지역에서 쓴다)가 빠진 반쪽짜리**.
  4. 그래서 배터리·전기차·열(남을 때 저장) + VPP(묶어서 관리) + 직접거래·지역 요금(제주에서 싸게 쓰게) → **"지소"를 채운다**.
  5. 지산 + 지소가 둘 다 되면 이익(아낀 돈·발전 수익)이 지역에 남는다 → 주민 참여·이익공유.
- **비유:** 동네 텃밭. 텃밭(분산에너지)을 많이 만들어도 냉장고(저장)·동네 장터(직접거래·지역 요금)가 없으면 채소가 썩는다(출력제어). 텃밭 + 냉장고 + 장터가 다 있어야 "우리 동네에서 길러 우리 동네에서 먹는다(지산지소)".
- **연결 문장 예시:** "분산에너지는 전기를 쓰는 곳 가까이에서 만들게 해 '지산'을 가능하게 했습니다. 하지만 제주는 만든 전기를 다 쓰지 못해 버리고 있어, '지소'가 빠진 상태입니다. 따라서 분산에너지 정책의 진짜 목표는 저장·유연성 자원과 지역 요금으로 '지소'까지 채워 지산지소를 완성하는 것입니다."
- **주의:** 지산지소는 법에 나오는 정식 용어가 아니라 정책·연구에서 쓰는 말(일본 地産地消에서 온 말). 리포트에서는 "지역에서 생산해 지역에서 소비하는 지산지소"처럼 처음에 풀어서 쓰기(크리링 판단, 법 조문에서 확인한 건 아님).
