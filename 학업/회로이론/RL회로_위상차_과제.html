RL 직렬회로에서 출력전압과 입력전압의 위상 차이

회로: 입력전압 vin = Vm sin ωt 에 저항 R과 인덕터 L이 직렬로 연결된 회로. L 양단, R 양단을 각각 출력으로 본다.

0. 기본 해석 (전류 구하기)

임피던스   Z = R + jωL,    |Z| = √(R² + (ωL)²),    θ = tan⁻¹(ωL / R)
전류   I = Vin / Z = (Vm / |Z|) ∠ −θ   → 전류는 입력전압보다 θ 만큼 뒤진다(지상)

1) L 단자의 출력전압과 입력전압의 위상 차이

VL = jωL · I = (ωL·Vm / |Z|) ∠ (90° − θ)

인덕터 전압은 전류보다 90° 앞서고, 전류는 입력보다 θ 뒤지므로 입력전압 기준으로는 (90° − θ) 만큼 앞선다.

VL은 입력전압보다 φL = 90° − tan⁻¹(ωL/R) = tan⁻¹(R / ωL) 만큼 앞선다(진상, lead).
(0° < φL < 90°, 크기비 |VL/Vin| = ωL / √(R² + ω²L²))

2) R 단자의 출력전압과 입력전압의 위상 차이

VR = R · I = (R·Vm / |Z|) ∠ −θ

저항 전압은 전류와 위상이 같으므로 입력전압보다 θ 만큼 뒤진다.

VR은 입력전압보다 φR = tan⁻¹(ωL / R) 만큼 뒤진다(지상, lag).
(0° < φR < 90°, 크기비 |VR/Vin| = R / √(R² + ω²L²))

3) 페이저도

VR과 VL은 항상 서로 90° 차이이고, 두 전압을 더하면(벡터합) 입력전압이 된다 (KVL).

4) 주파수에 따른 변화 (정리)

주파수θ = tan⁻¹(ωL/R)VL 위상 (입력 기준)VR 위상 (입력 기준)
ω → 0 (저주파)0°+90° (앞섬), 크기 → 00° (같은 위상), 크기 → Vin
ω = R/L (차단주파수 fc = R/2πL)45°+45°, 크기 = Vin/√2−45°, 크기 = Vin/√2
ω → ∞ (고주파)90°0° (같은 위상), 크기 → Vin−90° (뒤짐), 크기 → 0

→ L 단자 출력은 고역통과 필터(HPF), R 단자 출력은 저역통과 필터(LPF)처럼 동작한다.

결론

1) L 단자: 출력이 입력보다 tan⁻¹(R/ωL) = 90° − tan⁻¹(ωL/R) 만큼 앞선다.
2) R 단자: 출력이 입력보다 tan⁻¹(ωL/R) 만큼 뒤진다.
두 출력전압끼리는 항상 90° 차이가 난다.
