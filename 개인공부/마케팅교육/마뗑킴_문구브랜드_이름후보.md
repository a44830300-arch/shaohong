# 마뗑킴 자회사 문구 브랜드 — 이름 후보 (2026-11-12)

- 컨셉: 브랜드명 = '하루'라는 뜻의 프랑스어
- 라인업: **Matin 마뗑(아침) / Après-midi 아프레미디(오후) / Soir 수아르(저녁) / Nuit 뉘(밤) / Aube 오브(새벽)** (2026-11-25 밤·새벽 추가, 강정준비준 요청. 새벽은 Aube 외에 Aurore 오로르·Petit matin 프티 마뗑도 있었음, 상표 검색 안 함)
- 상태: 브랜드명 **아직 안 정함** (강정준비준이 고른다)

## 크리링 추천 (크리링 판단, 상표 검색 안 함)

1. **Journée**: '하루 전체'라는 뜻이라 아침·오후·저녁 라인업을 묶기 좋다.
2. **Jour après Jour**: 라인업의 Après-midi와 'après'가 겹쳐 말맛이 있고, 매일 쓰는 문구와 뜻이 맞다. 다만 길다.
3. **Jour**: 짧고 쉽지만 흔한 단어라 겹치는 브랜드가 있을 수 있다.

## 슬로건 방향 (2026-11-12)

- **버린 방향:** 브랜드명처럼 '하루 내내'를 말하는 슬로건 → ① 건방짐 ② 피로함(매일 써야 할 것 같음) ③ 짜침 ④ 너무 포괄적
- **정한 방향:** '순간' — 소중한 순간, 기록하는 순간, 마음을 표현하고 싶은 순간, 기억·추억하고 싶은 순간, 기록이 필요한 순간
- 구조: 브랜드명 = 하루(그릇), 슬로건 = 그 하루 속 순간(담는 것)

| # | 국문 | 영문 |
|---|---|---|
| 1 ⭐ | 남기고 싶은 순간에 | For the moments worth keeping |
| 2 ⭐ | 순간을 쓰다 | Write the moment |
| 3 | 쓰고 싶은 순간이 오면 | When a moment wants to be written |
| 4 | 마음이 머문 순간 | Where your moment stays |
| 5 | 간직할 순간들을 위해 | Pour les moments à garder (프랑스어) |

- 상태: 아직 안 정함 (강정준비준이 고른다). 같은 문구를 쓰는 브랜드가 있는지 검색 안 함.

### 속담·격언과 연결한 슬로건 후보 (2026-11-12)

| # | 바탕 속담·격언 | 슬로건 (국문 / 영문 / 프랑스어) |
|---|---|---|
| A ⭐ | 프랑스 속담 *Les paroles s'envolent, les écrits restent* (말은 날아가고 글은 남는다, 라틴어 Verba volant, scripta manent에서 옴) | 순간은 날아가도, 기록은 남는다 / Moments fly, words stay / Les moments s'envolent, les écrits restent |

| C | 프랑스 속담 *Petit à petit, l'oiseau fait son nid* (조금씩 새는 둥지를 짓는다) | 순간이 모여 하루가 된다 / Moment by moment, a day is made |
