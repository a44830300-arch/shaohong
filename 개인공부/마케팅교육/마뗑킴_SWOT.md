# 마킴 SWOT 분석 (2026-11-06 크리링 정리)

> 강정준비준이 피그마 '마케팅' 파일에 적은 메모(S·W·O·T 4장)를 바탕으로, 기존 조사 자료(`마뗑킴_1주차_자료.md`, `마뗑킴_뉴스_2024-2026.md`)의 근거를 붙여 정리함.
> 🙋 = 강정준비준 메모 · ➕ = 크리링이 더한 것 · ❓ = 확인 필요

## 한 줄 결론
**해외 성장과 팬덤은 강하지만 '빅로고 옷' 이미지는 질리기 시작했다 → 이미 시작한 예술·뷰티·공간 협업을 하나의 라이프스타일로 묶어 브랜드 수명을 늘려야 한다.**

## S 강점
1. 🙋 **계속 오르는 매출**: 2025년 매출 2,201억 원(+33.9%), 영업이익 445억 원, '3마' 중 1위. 창업자가 나간 뒤에도 꺾이지 않고 상승 중
2. 🙋 **해외 성공**: 해외 거점 5개(2024 말) → 22개(2025 말) → 26개(2026.8). 홍콩·마카오·대만 독점 유통 계약(5년 매출 목표 약 1,615억 원, 2024.4 발표). 대만 2026년 1~8월 매출 +163%
3. 🙋 **2030 여성·온라인 팬덤**: 온라인에서 큰 팬덤 → 오프라인(성수 210평 플래그십, 명동, 도산)으로 넓힌 뒤에도 인기 유지
4. 🙋 **뛰어난 마케팅·모델 선택**: 2026 앰버서더 5명(리즈·제노·모모·리노·김채원). 김채원(겨울 패딩)과 첫 남성 앰버서더 제노 → 남성복으로 넓히는 발판
5. 🙋 **착한 액세서리 가격**: 가방·지갑으로 처음 사 보는 문턱이 낮음
6. 🙋 **올해 영역을 크게 넓히는 중**: 라네즈 뷰티 협업, 첫 아이웨어, 아티스트 전시(3천 명+), 매장 외벽 아트 프로젝트, LG트윈스 협업, 성수 매장 안 커피 정원 → 미션(라이프스타일 확장)의 씨앗이 이미 있음

## W 약점
1. 🙋 **브랜드 역사가 짧음**: 오래된 브랜드처럼 내세울 이야기(헤리티지)가 약함
2. 🙋 **여성적 이미지가 강함**: 남성·가족 고객으로 넓히기 어려움 (2026 가을 남녀 공용 'PURE PLAY'로 보완 중)
3. 🙋 **빅로고가 너무 많이 소비돼서 질림**: 로고 = 마킴이라 유행이 지나면 같이 식을 위험
4. 🙋 **창업자 김다인 대표가 나감**(2023.10 사임): 브랜드의 얼굴·이야기를 들려줄 사람이 비어 있음
5. ➕ **협업이 많지만 흩어져 있음**: 뷰티·안경·야구·전시가 따로따로라 "마킴다운 생활"이 무엇인지 한 줄로 안 묶임 (크리링 의견)

## O 기회
1. 🙋 **방한 관광객(특히 중국인) 증가**: 국내 매장 손님 중 외국인 비중이 높아 바로 매출로 이어짐 ❓ 관광객 수 통계 붙이기
2. 🙋 **한국 이미지가 계속 좋아짐**: K-팝·K-뷰티 인기 → 한국 브랜드에 대한 관심 계속 늘 것
3. 🙋 **환율**: ❓ 아래 "확인할 것" 참고
4. ➕ **업계가 '탈패션' 중**: 옷만 팔아선 한계라 패션 브랜드들이 카페·뷰티·공간으로 넓히는 흐름(메종키츠네 '카페키츠네', 젠틀몬스터 '누데이크') → 라이프스타일 확장이 자연스러운 때
5. ➕ **새 시장**: 베트남 1호점(2026.10, 하노이), 중국 본토·세네갈 진출 계획

## T 위협
1. 🙋 **거리에서 점점 안 보이기 시작함**: 유행이 식는 신호
2. 🙋 **국내 오프라인 매출을 외국인이 많이 차지함**: 관광 경기·환율·나라 사이 관계가 나빠지면 매출이 바로 흔들림 ❓ 기사로 확인된 것은 "도산점 외국인 매출이 한국인보다 조금 더 많음(2024)"까지 → "대부분"이라고 쓰려면 근거 더 찾기
3. ➕ **'3마' 경쟁**: 마리떼 프랑소와 저버 매출 +27.2%(대명화학 자금력), 마르디 메크르디는 이미 헬로선라이즈와 라이프스타일 협업 중
4. ➕ **중국 본토 진출의 어려움**: 개점 확인 기사가 아직 없고, 현지 비슷한 제품(카피)과 경쟁해야 함

## SWOT → 미션 연결 (방향 힌트)
- **S×O**: 외국인 팬덤 + 관광객 증가 → 외국인이 꼭 들르는 "마킴 생활 공간"(카페·전시·굿즈가 있는 매장)으로 라이프스타일 확장
- **W×T**: 빅로고 피로 + 유행 식음 → 로고 없이도 마킴이 느껴지는 생활 아이템·경험으로 브랜드 이미지 바꾸기

## 확인할 것
- **환율 메모 "환율이 계속 떨어지고 있음"**: 환율(1달러=○원)이 떨어지면 원화가 비싸져서 외국인에게 한국 쇼핑이 비싸짐 → 오히려 **위협**. "원화 가치가 떨어짐(환율이 오름)"이라는 뜻이면 외국인에게 싸져서 **기회**. 어느 쪽인지 정해서 칸을 옮기기.
- "중국인 관광객 증가"는 피그마에서 S장에 있었지만 회사 밖 흐름이라 **O(기회)**로 옮김.
