# 마뗑킴 캠페인 보고서 강사 피드백 정리 (2026-11-12 받음)

> 강사 피드백을 주제별로 묶어 정리. "고칠 일"은 다음 제출 전에 할 일.

## 한 줄 요약
분석에 **숫자·근거가 없고**, 분석 → 전략 → 캠페인이 **이어지지 않으며**, 문구 브랜드가 **실제로 어떻게 생겼는지(이름·제품·가격·유통·예산)가 빠져 있다.** 3번(실행안)이 가장 중요.

---

## 1. 숫자가 거의 없다 (근거·출처 붙이기)

느낌으로 쓴 문장('매출 계속 상승', '국내 인기 식는 중', '길에서 점점 안 보임')에 숫자를 붙여야 한다.

강사가 예로 준 숫자 (기사에서 바로 찾을 수 있는 것):
- **연매출:** 2020년 약 50억 → 2024년 1,500억 → 2025년 2,000억 규모 (뉴스1, 머니투데이)
- **성장 배경:** 2021년 하고하우스 투자 이후 백화점 입점으로 성장
- **매장 고객:** 성수·명동 등 관광 상권 매장은 방문객 **90% 이상이 해외 고객**, '서울 익스클루시브' 제품 인기 (머니투데이, 2025.12)
- **해외:** 홍콩·대만·마카오·일본·태국·불가리아·몽골 진출, 태국 센트럴그룹과 5년 600억 유통 계약
- **잡화 역량:** 카드지갑·캔버스백으로 2025 APEC 공식 협찬, 코치·케이스티파이 협업
- **그룹 차원:** 하고하우스가 한남에 '모자이크 한남' 오픈, 커피 브랜드까지 입점 → 이미 라이프스타일로 움직이는 증거

💡 핵심: **매장 손님 90%가 외국인 = 약점이 아니라 가장 큰 기회.** '여행 노트'를 관광객에게 팔 곳이 이미 있다.

**고칠 일**
- [ ] SWOT 항목마다 **근거 한 줄 + 출처** 붙이기
- [ ] 근거를 못 찾은 항목은 빼거나, 검색량 추이처럼 확인 가능한 지표로 바꾸기

## 2. 앞뒤가 안 맞는 부분

### SWOT (p.2)
- [ ] '매출 계속 상승'과 '국내 인기 식는 중'을 숫자로 나누기 → 예: 해외·관광객 매출은 큼 / 국내 2030 체감 인기는 정체. 사례·데이터 추가
- [ ] '외국인 매출이 더 많다'를 약점에서 **기회** 쪽으로 다시 보기
- [ ] 위협이 '3마와 로고 비슷' 한 줄뿐 → 문구 사업 자체의 위협 추가: **가격 경쟁, 재고 부담, 패션 브랜드 굿즈 피로감**
- [ ] 강점·약점에 같은 내용이 겹치지 않게
- [ ] **SO / WO / ST / WT 전략**을 한 줄씩 뽑고, 캠페인 방향이 그중 하나에서 나오게

### 캠페인 방향 (p.3)
- [ ] WHY('여성 중심 이미지에서 벗어나기')와 페르소나(28세 여성 1명)가 따로 논다 → **WHY를 바꾸거나, 남성/외국인 페르소나 추가** 중 하나
- [ ] 장면이 너무 많다(펜으로 노트 쓰기, 러닝, 사진 붙이기, 건강한 여행/오락성 여행 두 버전) → '쓰다'를 골랐으면 **언제·어디서·뭘 쓰는지 장면 하나로** 좁히기

### 경쟁사
- '선점하고 있다', '이미지가 겹친다', '블랙 앤 화이트가 겹친다'는 이유가 아니라 **인상**이다.
- [ ] 경쟁사마다 **같은 기준**으로 비교: 가격대(대표 제품 실제 가격) · 주 고객 · 판매 채널 · 배울 점 · 다르게 갈 점
- [ ] **포지셔닝 맵** 한 장 (예: 가격 × 감성/기능) → 마뗑킴 문구가 들어갈 빈자리 보이게
- [ ] **젠틀몬스터**는 경쟁자가 아니라 패션 → 디저트·뷰티로 넓힌 **참고 사례**로. 어떤 순서로 넓혔는지 정리

### 페르소나
- 나이·직장·취향만으로는 뭘 만들고 어디에 광고할지 못 정한다.
- [ ] 채울 것: 지금 어떤 다이어리·펜을 **얼마에 어디서** 사는지 / 마뗑킴에서 뭘 사 봤고 **요즘 왜 덜 사는지** / 지금 문구에서 **불편한 점** / 하루에 **어떤 앱을 언제** 보는지 / **어떤 순간에 지갑을 여는지**
- [ ] 페르소나 **2명**: ① 국내 기존 팬 1명 ② 매장을 찾는 해외 관광객 1명

## 3. 실제로 뭘 할지가 빠져 있다 ⭐ 가장 중요

'자회사 문구 브랜드 만들기'라는 목표만 있고 브랜드가 어떻게 생겼는지는 없다. **대표님께 보고한다고 생각하고** 아래에 답하기. 각 답은 앞의 분석에서 이어져 나와야 한다.

| # | 질문 | 답해야 할 것 |
|---|---|---|
| 1 | 컨셉 | 고객의 **어떤 순간**을 책임지나? 한 문장. ('감성 문구'처럼 아무 데나 붙는 말 금지) |
| 2 | 브랜드명 | 마뗑킴 이름 그대로 vs 새 이름. **후보 2~3개 + 고른 이유** |
| 3 | 슬로건 | **국문 + 영문** (손님 대부분 외국인 → 영문 필수) |
| 4 | 이미지 | 본 브랜드와 같이 갈 것/다르게 갈 것, 키워드 3개, 컬러·로고 방향, **무드보드 1장** |
| 5 | 제품 라인업 | 처음 몇 개, 대표 제품, 제품별 가격·소재·다른 점 |
| 6 | 가격 | 경쟁사보다 위/아래, **실제 가격 옆에 놓고 비교** |
| 7 | 유통 | 어디서 먼저 팔고 어디로 넓힐지, 순서와 이유 |
| 8 | 단계별 계획 | 언제 뭘 하고, **다음 단계로 넘어가는 기준은 숫자로** |
| 9 | 마케팅 | 알리기 / 사게 하기 / 다시 사게 하기 — 각각 채널·콘텐츠·협업(**협업 상대 이름까지**) |
| 10 | 예산과 목표 | 항목별 금액·비중, 성공 판단 숫자 3~5개. **가정한 숫자는 '가정'이라고 표시** |

- [ ] **왜 문구인가?** 미션은 '라이프스타일'인데 왜 문구인지 설명 필요 → **홈 · 향 · F&B · 문구** 후보를 놓고 ① 마뗑킴 강점 ② 고객 ③ 돈이 되는지 기준으로 비교해서 문구를 고른 과정 보여 주기

## 4. 강사가 준 예시 (구체성 참고용 — 그대로 쓰지 말 것)

> 팀의 '마뗑킴, 쓰다' 방향을 살려 좁힌 예시. 가격·예산·일정은 강사가 **임의로** 넣은 숫자. 우리 팀 답으로 바꿔서 낼 것.

- **컨셉:** matin = 프랑스어 '아침' → **'아침에 쓰는 한 페이지'**. 텍스트힙·모닝페이지 트렌드와 연결, 창업자가 빠진 자리를 '아침을 쓰는 사람'이라는 새 이야기로 채움
- **브랜드명:** MATIN PAGES (후보: 마뗑 노트, KIM'S DESK). 처음엔 'MATIN PAGES by MATIN KIM' → 반응 좋으면 분리
- **슬로건:** 하루의 첫 페이지 / Write your matin.
- **이미지:** 아침 햇빛·여백·손글씨. 빅로고 대신 작은 각인 + 한글 '마뗑' 로고, 크림색 종이 + 검정 포인트 (로고만 찍은 굿즈처럼 보이는 문제 피함)
- **타깃:** 국내 2030 기존 팬(아침 루틴·기록 습관) / 성수·명동 매장 해외 관광객(여행 기록·서울 기념품)

**첫 출시 제품 5개**

| 제품 | 가격 | 포인트 |
|---|---|---|
| 모닝페이지 100일 저널 (대표) | 22,000원 | 날짜 없는 100일, 매일 세 문장 질문 |
| 서울 트래블 노트 (서울 매장 한정) | 28,000원 | 한글 로고, 매장별 스탬프 칸, 사진 포켓 |
| 레더 노트 커버 | 79,000원 | 가방·지갑 가죽 그대로, 이니셜 각인 |
| 콜라보 펜 (한정) | 25,000~40,000원 | 펜 브랜드와 공동 기획, 시즌마다 색 변경 |
| 스티커·마스킹테이프·북마크 | 5,000~15,000원 | 계산대 앞 가벼운 상품 |

- **유통:** 성수·명동 플래그십 안 '아침 책상' 코너 → 자사몰·온라인 패션 플랫폼 → 문구 박람회로 편집숍 입점 → 홍콩·대만·일본 매장
- **마케팅:** 앰버서더가 아침에 세 문장 쓰는 짧은 영상 시리즈 / #마뗑페이지100 챌린지(100일 인증 시 레더 커버 각인 무료) / 관광객용 성수·명동·한남 매장 스탬프 투어 + 모자이크 한남 카페 '아침 쓰기 세트' / 레더 커버 구매자에게 리필 속지 정기 배송(재구매)
- **예산·목표 (가정):** 런칭 6개월 총 3억 → 6개월 매출 6억(예산 2배), 신규 고객 40%, 챌린지 인증 3,000건, 저널 구매자의 레더 커버 구매 10%
- **단계별 계획:**
  1. 1~3월 테스트: 펜 콜라보 한정판 1종 + 성수 2주 팝업 → **한정판 완판 + 재구매 의향 60% 이상**이면 다음
  2. 4~6월 런칭: 5종 출시, 성수·명동 코너·자사몰, 챌린지 시작 → **6개월 매출 6억 + 신규 40%** 넘으면 다음
  3. 하반기 확장: 해외 매장 입점, 리필 정기 배송, 독립 브랜드 분리 여부 결정
- 팀이 쓴 '작은 콜라보부터'를 **단계 + 기준**으로 바꾸면 된다. 날짜보다 기준이 중요하고, 못 넘으면 방향을 고친다.

## 5. 다음 제출 전 체크리스트

- [ ] SWOT 항목마다 근거와 출처가 있다
- [ ] 강점과 약점에 같은 내용이 겹치지 않는다
- [ ] SWOT에서 전략(SO/WO/ST/WT)을 뽑았고, 캠페인이 거기서 나왔다
- [ ] 왜 문구인지 다른 후보와 비교해서 설명했다
- [ ] WHY와 페르소나가 맞는다 (페르소나 2명 이상)
- [ ] 경쟁사를 같은 기준으로 비교하고 포지셔닝 맵을 그렸다
- [ ] 브랜드명, 슬로건, 이미지 방향이 있다
- [ ] 대표 제품과 라인업, 가격이 있다
- [ ] 유통 순서, 마케팅, 예산, 목표 숫자가 있다
- [ ] 단계마다 넘어가는 기준이 숫자로 있다
- [ ] 캠페인 장면이 하나로 좁혀졌다
