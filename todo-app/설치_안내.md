# 할 일판 앱 설치 안내 (나만 쓰는 앱)

할 일판을 Claude 밖에서 혼자 뜨는 앱으로 만든 것이다. 앱 파일은 이 저장소의 `todo-app/` 폴더에 있고,
본 공책(main)이 바뀌면 Netlify가 저절로 새 버전을 올린다. 인터넷에는 `todo-app/` 폴더만 올라간다.

처음 한 번만 아래 4단계를 하면 된다. (Todoist 열쇠·구글 출입증은 각 기기 안에만 저장된다)

## 1단계. 앱 주소 만들기 (Netlify, 무료, 5분)

1. https://app.netlify.com 에서 **Sign up → GitHub로 가입**
2. **Add new project → Import an existing project → GitHub**
3. GitHub가 권한을 물으면 **shaohong 저장소만** 허용
4. `shaohong` 저장소를 고르고, 브랜치는 `main` 그대로 → **Deploy** (설정은 저장소의 `netlify.toml`에 다 들어 있어서 건드릴 것 없음)
5. **Project configuration → Change project name**에서 이름을 바꾸면 주소가 `https://이름.netlify.app`이 된다

## 2단계. Todoist 열쇠 (1분)

Todoist → 설정 → **연동 → 개발자** 탭 → **API 토큰 복사** → 앱의 ⚙ 설정 ①칸에 붙여넣기

## 3단계. 구글 캘린더 등록 (한 번만, 15~20분)

1. https://console.cloud.google.com 접속 → 위쪽 프로젝트 선택 → **새 프로젝트** (이름: 할일판)
2. 검색창에 **Google Calendar API** → **사용**
3. 왼쪽 메뉴 **Google 인증 플랫폼(OAuth 동의 화면) → 시작하기**
   - 앱 이름: 할일판 / 지원 이메일: 내 지메일 / 대상: **외부** / 연락처: 내 지메일 → 만들기
4. **대상(Audience) → 테스트 사용자 → 내 지메일 추가**
5. **클라이언트 → 클라이언트 만들기 → 웹 애플리케이션**
   - 승인된 자바스크립트 원본: 앱 ⚙ 설정에 보이는 첫 번째 주소 (예: `https://이름.netlify.app`)
   - 승인된 리디렉션 URI: 앱 ⚙ 설정에 보이는 두 번째 주소 (예: `https://이름.netlify.app/`)
   - 만들기 → **클라이언트 ID 복사** → 앱 ⚙ 설정 ②칸에 붙여넣기 → **구글 연결**
6. "Google에서 확인하지 않은 앱" 화면이 나오면 **계속** (내가 만든 앱이라 괜찮음)

- 구글 출입증은 1시간짜리라, 앱을 다시 열 때 화면이 한 번 깜빡이며 저절로 이어진다.
- 테스트 모드라서 일주일쯤마다 **[구글 다시 연결]** 버튼이 뜰 수 있다 → 누르면 끝.

## 4단계. 기기에 설치

- **갤럭시:** 크롬으로 앱 주소 열기 → 오른쪽 위 ⋮ → **홈 화면에 추가 → 설치**
- **컴퓨터:** 크롬으로 앱 주소 열기 → 주소창 오른쪽 **설치 아이콘(모니터 모양)** → 설치
- 폰과 컴퓨터에서 각각 ⚙ 설정에 Todoist 열쇠·구글 연결을 한 번씩 한다.

## 참고

- 타이머·스톱워치·오늘 총 시간은 기기마다 따로 기억한다 (Claude 할 일판에 쌓인 기록은 옮겨지지 않음).
- 할 일판(Claude 페이지)과 앱 둘 다 계속 쓸 수 있다. 규칙이 바뀌면 둘 다 같이 고친다.
