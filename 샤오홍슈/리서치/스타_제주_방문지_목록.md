# 중국인이 좋아하는 스타들의 제주 방문지 (2026-11-25 조사)

강정준비준이 준 "중국 인기 한국 연예인 연도별 순위(2010~2025)" 속 연예인 + 목록 밖 중국 인기 한국 스타 + 중국 스타가 제주에서 들른 곳·사진 찍은 곳을 모았다.

**확실도 표시**
- ✅ 기사·공식 자료에서 확인
- 🟡 팬 정리글·여행 사이트 한 곳에만 나옴 (쓰기 전에 다시 확인)
- ❌ 찾아봤지만 제주 장소를 못 찾음

> 모든 가게의 **지금 영업 여부는 확인 안 함.** 대부분 2018~2024년 기사라 문을 닫았거나 이름이 바뀌었을 수 있다(네이버지도로 확인 필요).

## 크리링 생각 (콘텐츠로 쓸 때)

1. **지민 5곳이 가장 쓸 만하다** — 기사로 다 확인되고 제주관광공사가 공식 이벤트까지 했다. 한 코스로 묶기 좋다(연동 → 협재·문쏘 → 남경미락 → 스누피가든).
2. **드라마 촬영지는 「폭싹 속았수다」·「킹더랜드」·「웰컴투 삼달리」·「올인」 순** — 공식 기사가 많고 장소가 실제로 남아 있다(바다·오름·포구라 문 닫을 걱정이 없음).
3. 🟡 표시는 올리기 전에 네이버 블로그·네이버 통합검색으로 한 번 더 확인한다.
4. 연예인 사진은 쓰지 않는다(초상권·저작권). 장소 사진은 직접 찍고, 글에서 "○○가 다녀간 곳"이라고만 쓴다.
