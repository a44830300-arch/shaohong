# 잡지 느낌 디자인 레퍼런스 사이트 (2026-10-29)

샤오홍슈 카드뉴스를 잡지 느낌으로 만들 때 참고할 곳.

## 1. 가장 먼저 볼 곳

| 사이트 | 이런 걸 찾을 수 있어요 |
|---|---|
| **샤오홍슈** (rednote.com) | 중국 사람들이 좋아하는 잡지 스타일을 바로 볼 수 있어요. 아래 검색어를 넣어 보세요. |
| **Pinterest** (pinterest.com) | 잡지 표지·속지 레이아웃이 가장 많아요. 마음에 드는 걸 하나 누르면 비슷한 디자인이 계속 나와요. |
| **Coverjunkie** (coverjunkie.com) | 전 세계 잡지 표지만 모아 둔 곳이에요. 표지 1장째 디자인 참고하기 좋아요. |

## 2. 여행 잡지 (제주 콘텐츠와 분위기가 잘 맞아요)

- **CEREAL** — 여행 잡지. 여백이 많고 사진이 크고 차분한 느낌
- **Kinfolk** — 따뜻하고 감성적인 사진 + 깔끔한 글씨
- **매거진 iiin** — 제주를 다루는 잡지라 제주 사진·글 배치 참고하기 좋아요
- 이 잡지 이름을 Pinterest에 검색하면 속지 사진이 많이 나와요.
