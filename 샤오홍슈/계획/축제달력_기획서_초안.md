## 3. ✅ 넣기로 한 것

### 내용
- **축제마다 그 축제의 실제 사진 (꼭).** 다른 축제 사진이나 아무 제주 풍경으로 대신하지 않는다. (2026-11-02 자체 피드백 1번)
- **"어디서, 언제, 얼마"가 바로 보이게:** 축제 이름 · 날짜(요일 포함) · 장소 · 가격/무료 · 가는 법
- **축제 날짜는 비짓제주(visitjeju.net) 축제 페이지 기준.** 공식 발표 전이면 확인 후 넣는다
- **넣을 축제는 강정준비준이 고른다.** 크리링은 후보만 찾아 Todoist "샤오홍슈 아이디어"에 넣는다(매주 일·월 축제 탐색)
- **중국 연휴 챙기기:** 춘절(설)·노동절(5/1)·국경절(10/1) 전에는 그 연휴에 열리는 축제를 미리 넣는다

### 디자인
- **지도 + 축제마다 테마 위치포인트 1개.** 모양은 귤 핀 규칙(56x74, 흰 외곽선 1, 귀여운 얼굴·볼터치, 핀 아래 납작한 진갈색 30% 그림자)
  - 만들어 둔 핀 (`샤오홍슈/축제달력/위치포인트/`): 노래방마이크, **마이크(실버·보라, 이걸로 선택)**, 결혼 반지, 웨딩케이크, 커플 하트, 배낭, 야시장 홍등 + 얼굴 없는 버전
- **달력 칸 규칙** (예전 템플릿에서 가져옴): 날짜는 두 자리(01), **일요일은 빨간색(#FF1D1D)**, 제목 1줄 = 월(예: 11月), 제목 2줄 = 기간(예: 11.02 - 11.15)
- **글씨:** 숫자 Inter Bold + 한자 Noto Sans SC Bold, 흰 글씨 + 검정 그림자 (크기·자간 고정)
- **스티커:** 날짜 칸에 축제 스티커 (노랑 스마일·주황 윙크·파랑 선글라스·호박 등)

### 저장을 부르는 장치 (11월 월간계획에서 정함)
- 중국어 주소 + 한국어 주소 같이 적기 (택시 기사에게 보여 주려고 저장한다)
- 캡션 끝에 저장 유도 멘트: **建议码住** (jiànyì mǎzhù = 저장해 두세요)
- 올리고 일주일 뒤 **저장 수를 기록**한다 (일요일 주간 계획 때 기록표 채우기)

## 4. 🧪 시도하기로 한 것

- **"아이템 자체가 핀" 방식** (2026-11-01): 마이크 핀처럼 물방울 핀 대신 아이템 모양이 바로 핀이 되게. 새 핀을 만들 때 먼저 이 방식으로 제안한다
- **FunHaus(놀이공원) 트렌드** (2026-11-04 포스터 피드백 기준): 빨강·흰 줄무늬, 아치·곡선, 아주 큰 숫자, 휘어진 글씨. 한 장에 트렌드 하나만
- **잡지 표지 공식**: 큰 사진 + 큰 제목 + 작은 정보 3~4줄
- **한 장 요약표**를 마지막 장에 (날짜·시간·입장료·가는 버스 한눈에)
- **축제 상세 공략 장** — 节庆详细攻略 (jiéqìng xiángxì gōnglüè = 축제 상세 공략). 피그마 `<작업중>` 17·18번 장처럼 가게·장소 약도 카드(가는 시간 / 영업시간 / 주소)를 붙여 보기
- **축제 소개 피드·자체 홍보 디자인과 엮기**: 달력에서 예고 → 축제 소개 피드로 자세히 → 반응 캡처를 주최사에 보여 주기 (휴애리 동백축제부터)
- **11월 목표 확인**: 축제달력 5개 + 축제 소개 피드 5개 = 축제 피드 10개, 저장 100개 넘는 글 5개 이상

| 매주 **수요일** 2주짜리 달력 올리기 | 일요일 오전 10시, 날씨달력과 함께로 옮김 |
| 날씨달력 캡션의 "🎪 每周三更新更多节庆信息" 줄 (měi zhōu sān gēngxīn gèng duō jiéqìng xìnxī = 매주 수요일 축제 정보 업데이트) | 2026-11-01 뺌. 다시 넣으라고 할 때까지 안 씀 |
| 크리링이 축제달력을 대신 만들기 | 강정준비준이 직접. 크리링은 위치포인트만 |
| 크리링이 스티커·축제를 마음대로 더하기 | 강정준비준이 고른 것만 넣는다 |
