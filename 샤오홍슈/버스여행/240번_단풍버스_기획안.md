# 240번 버스 가을 단풍여행 — 샤오홍슈 기획안 (2026-11-03)

## 한 줄 컨셉
**"차 없이도 OK! 버스 한 번으로 한라산 단풍길(1100도로) 넘기"**

- 타겟 페르소나: **② 즉흥형 2030 여성** (메인) — 단풍은 지금이 절정이라 "이번 주에 바로 갈 수 있는 법"이 필요한 사람
  - 보조: ① 계획형 2030 여성 (저장해 두고 내년 가을에 씀)
- 왜 먹히나: 중국인 관광객은 대부분 제주에서 렌터카를 못 빌려서 버스·택시로 다닌다. 1100도로 단풍은 보통 "드라이브 코스"로만 소개돼서, **버스로 가는 방법**은 아직 적다 → 선점 포인트.
- 결제 포인트: 제주 버스의 'ON나라페이' 단말기에서 **알리페이·위챗페이·비자 등 해외 간편결제**가 된다(제주도 발표, 2026-06 기사). → **타는 날 단말기 사진을 꼭 찍어서 실제로 되는지 확인**.

## 타이밍
- 산림청 예측: **1100도로 단풍 절정 11/6 (금)**, 한라수목원 11/19 (목). 예측이라 실제와 다를 수 있음.
- 단풍은 금방 지니까 촬영은 빠를수록 좋다. (올리는 날짜는 강정준비준이 정한다.)

## 240번 노선 (제주버스터미널 → 제주국제컨벤션센터)
제주버스터미널 → 한라병원 → 한라수목원 → 제주도립미술관입구 → 충혼묘지 → 한라산둘레길(천아숲길입구) → **어리목입구** → **1100고지휴게소** → 영실입구 → **영실매표소** → 영실입구 → **서귀포자연휴양림** → **거린사슴전망대** → 법정사입구 → 서귀포천문과학문화관 → 회수 → 중문사거리 → 제주국제컨벤션센터

- 터미널 → 어리목 약 40분, → 영실 약 55분, → 중문 약 1시간 20분.

## 촬영 동선 (반나절 추천안, 약 5시간)
| 시각(대략) | 할 일 |
|---|---|
| 09:10 | 제주버스터미널에서 240번 탑승 (버스·번호판·결제 단말기 촬영) |
| 약 09:57 | **1100고지휴게소** 하차 — 고지대 단풍, 1100고지 습지 데크, 휴게소 (약 45분) |
| 약 10:47 | 다음 버스(10:00 출발 차) 타고 남쪽으로 |
| 약 11:00 | **서귀포자연휴양림** 하차 — 단풍 숲길 (09:00~18:00, 입장 마감 17:00) (약 1시간 30분) |
| 약 13:30 | 돌아오는 버스(컨벤션 13:10 출발 차) 탑승 |
| 약 14:30 | 제주버스터미널 도착 |

- 중간 정류장 도착 시각은 앞뒤 시간으로 계산한 **대략**이다. 정류장에서 10분 일찍 기다린다.
- 영실은 정류장(영실매표소)에서 영실휴게소까지 오르막 약 2.5km, 어리목은 정류장에서 입구까지 약 1km 걸어야 해서 이번 동선에선 뺐다(등산로는 단풍지도에서도 뺀 곳).
- 같은 날 **"사람들 옷차림 사진 찍기"**(토요일까지 할 일)도 고지대에서 같이 찍을 수 있다.
- Todoist의 "중국인 관광객들이 가는 관광코스 경험해보기"도 이 여행으로 해결된다.

- [ ] 정류장 표지판: 1100고지휴게소, 서귀포자연휴양림

- [ ] 서귀포자연휴양림 단풍 숲길 (사람 들어간 컷 + 풍경만 컷)

- [ ] 휴게소 화장실·매점 위치 (실용 정보)

## 게시물 구성안 (7장)
1. 표지 — 버스 + 단풍 사진, 제목
2. 왜 버스? — 운전 안 해도 됨, 요금, 알리페이·위챗페이 결제 (단말기 사진)
3. 노선 지도 — 터미널 → 1100고지 → 휴양림 → 중문 (핀 캐릭터·단풍잎 핀 재사용 가능)
4. 내려서 볼 곳 ① 1100고지휴게소
5. 내려서 볼 곳 ② 서귀포자연휴양림
6. 시간표 + 막차 주의 (1시간에 1대꼴, 겨울엔 막차 빨라짐)
7. 옷차림·꿀팁 — 산 위는 시내보다 훨씬 추움, 정류장 10분 전 대기, 돌아오는 차 시간 먼저 확인
